# 연구 결과와 현재 판단 — 2026-10-17 갱신

현재 연구는 **공개 활–현 실험에서 연주 가능 영역을 다른 운궁 속도와 현 표본으로 예측하고, 그 결론이 판정 기준과 물리적 가정에 얼마나 의존하는지 검증하는 연구**다. 자체 녹음·센서·추가 구매 없이 M2 노트북에서 수행했다.

**일반적으로 더 좋은 새로운 예측 방법은 아직 입증하지 못했다.** 독립 표본으로 정해 둔 A2에서 두 후보 모두 주 비교에 실패했다. 이 결과를 숨기거나 유리한 보조 비교로 대체하지 않는다. 계산과 재현 자료는 갖춰졌지만, 사용자가 요구한 높은 방법론적 novelty와 논문 완성은 별개의 미완료 목표다.

## 추가 표본에서 확인한 결과

A2의 원시 시행 6,000개 중 사전에 정한 기준을 통과한 5,892개를 평가했다. 점수는 세 속도 패널 각각에서 15개 고정 판정 규칙에 대한 최소 IoU를 구한 뒤 평균한 값이다. 정답은 연구에서 정한 신호 판정이며, 접촉 상태를 독립적으로 측정한 물리적 정답이 아니다.

| 고정된 주 비교 | 후보 | 비교 모델 | 결과 |
|---|---:|---:|---|
| 한 속도에서 학습한 강건 후보 대 학습원에서 선택한 logistic 기준 모델 | 0.635452 | 0.659570 | 개선 실패 |
| 두 속도에서 학습한 affine 흐름 대 폭을 고정한 절제 모델 | 0.653586 | 0.667870 | 개선 실패 |
| 같은 흐름 대 학습원에서 선택한 지수 모델 | 0.653586 | 0.662273 | 개선 실패 |

위 마지막 두 행은 같은 후보의 두 비교다. 한 속도·두 속도 학습은 입력 예산이 달라 별개로 해석한다. 전체 26개 모델과 보조 속도 쌍을 [완료 결과](lockbox_A2/README.md)에 보존했다. A2는 이제 관측한 자료이며, 다음에 방법을 바꾼 뒤 다시 미노출 검증이라고 부를 수 없다.

## 새로 구현하고 검증한 분석

1. **활 위치에 따라 폭 변화율이 달라지는 모델.** 전체 18개 학습 과제에서 평가했다. 첼로 평균은 기존 흐름보다 낮았고, 공개 바이올린 D현의 작은 평균 이득도 여섯 과제 중 두 곳에 국한됐다. 양쪽 자료에서 개선해야 한다는 기준을 통과하지 못했다. [전체 비교·독립 재현](../2026-10-13/conditional_transport_assessment.md).
2. **같은 판정 규칙으로 두 모델을 비교하는 분석.** 규칙을 바꿀 때 상대 순위가 뒤집히는 경우를 전부 계산했다. 각 모델의 최악 점수끼리 비교하는 것과 하나의 공통 규칙에서 우열을 비교하는 것은 서로 다른 질문이다. 기존 고정 평가 정의는 유지했다. [5,596개 비교와 의미](../2026-10-13/observer_dominance_audit.md).
3. **관측 범위와 폭 법칙의 제약을 분리하는 분석.** 각 위치에서 독립적인 경계를 허용할 때의 최소 불일치와, 하나의 폭 변화율을 강제할 때의 최소 불일치를 따로 계산했다. 모든 186개 조건에서 실제로 그 비용을 달성하는 경계도 구성해 확인했다. 추가 불일치는 첼로 최대 12행, 공개 D현 최대 3행이었다. [수식·전체 결과·계산 검증](width_law_assessment.md).

세 번째 계산은 자유로운 경계 중심을 허용한 **명목 제어값의 완화 문제**다. 실제 첼로 모델의 측정 위치·속도는 열 안에서도 다르고, 학습 목적과 평가 자료도 다르다. 작은 추가 불일치가 예측 손실의 원인을 밝히거나 배제하는 것은 아니다. 기존 집합 기반 식별과 최소 불일치 원리와의 차별성도 아직 충분하지 않다.

추가로 폭 변화율을 실제 학습 모델과 같은 `−2 ≤ k ≤ 2`로 제한했다. 186개 조건 중 6개에서 최소 불일치가 1행 또는 3행 늘었지만, 기본 첼로 판정과 모든 공개 D현 결과는 그대로였다. 범위 밖에 있던 23개 대표 해 중 17개는 같은 비용의 범위 안 해를 새로 구성할 수 있었다. [범위 제한 검증](width_bound_sensitivity.md)은 대표 해 하나의 위치와 최적 비용 자체의 변화를 구분한다. 역시 예측 성능 개선 결과는 아니다.

## 검증과 재현

[독립 A2 감사](lockbox_independent_audit.md)는 원본 아카이브 전체 MD5를 다시 계산하고, 별도 판정·좌표 변환·집합 연산으로 결과를 확인했다. 26개 모델의 확률값 153,192개는 최대 오차 5.55×10⁻¹⁶, 지표·요약값 4,694곳은 정확히 일치했다. 이는 구현 검증이지 독립 실험 횟수나 물리적 타당성의 증거가 아니다.

원시 자료·기존 체크포인트를 복사하지 않은 새 폴더에서도 공개 파일만으로 14개 체크포인트를 같은 해시로 복원하고, 26개 모델의 평가값 2,886개를 오차 없이 재현했다. 조건부 흐름과 폭 진단의 독립 감사 결과도 같았다. 설치된 Python 환경은 재사용했다. [실행 기록](public_reproduction.json), [최종 테스트 기록](../../docs/validation.md).

```bash
bash scripts/run_mac.sh python scripts/restore_frozen_models.py
bash scripts/run_mac.sh python research/2026-10-14/lockbox_release.py replay
bash scripts/run_mac.sh python research/2026-10-14/width_law_report.py
bash scripts/run_mac.sh python research/2026-10-14/width_bound_sensitivity.py --output reports/width_bound_replay.json
```

마지막 명령의 출력 폴더 `reports/`가 없다면 먼저 만든다. 범위 제한 분석도 별도의 깨끗한 폴더에서 전체 과학적 결과가 정확히 일치했다. [추가 재현 기록](public_bound_reproduction.json).

전체 연구에는 공개 첼로 현과 기존 논문의 바이올린 현 모노코드 자료가 사용됐다. 조립된 바이올린 전체에 대한 일반화나 연주 교육 효과를 검증한 것은 아니다.

## 다음 방법론이 넘어야 할 기준

다음 후보는 실제로 확인된 문제를 해결해야 한다. 판정 기준의 변화, 관측 범위 밖 경계, 명목값과 측정값의 차이 중 어떤 불확실성을 다루는지 정하고, 그 가정을 자료로 정당화해야 한다. 예측 집합을 제시한다면 좁다는 것만으로 충분하지 않고, 주장하는 범위가 정확하며 계산 가능한 근거가 필요하다.

현재보다 복잡한 모델을 추가하는 것만으로는 이 기준을 충족하지 않는다. 기존 정확 열거·단순 지수 모델과 비교해 새로운 계산상 이득 또는 검증 가능한 보장이 있어야 하고, 이미 본 A2에 맞춰 좋아진 결과는 개발 결과로 분리해야 한다. [선행연구와 남은 방법론 과제](../2026-10-13/next_method_audit.md), [논문화 가능 범위](../2026-10-13/paper_readiness.md)에 이 기준을 명시했다.
