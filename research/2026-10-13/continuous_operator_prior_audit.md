# Continuous threshold-operator oracle: closest-prior audit

Checked 2026-10-13. Proposed setting: fixed predictions on a finite dataset, with labels generated by one shared pair of thresholds over two observed features, subject to a declared threshold rectangle. Optimize worst-case Jaccard over the entire continuous operator family rather than a coarse parameter grid.

## Verdict

The proposed oracle is a useful, testable correctness improvement over the current 15-operator sensitivity grid. Its components are established: fractional programming, Jaccard linearization, and weighted quadrant sweeps. We did not identify an exact paper combining these ingredients for this particular **shared observation-operator sensitivity** problem in this targeted search. That is not sufficient to claim a novel general-purpose algorithm. The plausible contribution is the scientific evaluation formulation, exact operator-space auditing, carefully demonstrated consequences, and an efficient reproducible implementation with appropriate attribution.

## Mathematical scope and implementation checks

These are deductions for the proposed formulation, not claims of novel mathematics.

Let p_i in [0,1] be fixed model scores and y_i(theta) binary labels. Define A(theta)=sum_i p_i y_i(theta), B(theta)=sum_i p_i + sum_i (1-p_i)y_i(theta). For sum_i p_i > 0, B is positive and minimizing A/B reduces at candidate gamma to minimizing

`sum_i [p_i - gamma * (1-p_i)] * y_i(theta) - gamma * sum_i p_i`.

If the rule is a conjunction of two monotone feature thresholds plus fixed eligibility, this is a signed weighted orthant problem. A sweep and dynamic prefix aggregate suffice. The strict versus non-strict inequalities, ties, rectangle endpoints and the fixed eligibility predicate must be preserved exactly.

- A continuous threshold family induces only finitely many label vectors on a fixed dataset. Enumerating all feature breakpoints is exact for the declared predicate; no approximation by a uniform threshold grid is needed.
- O(k n log n) means k fractional-program iterations. Do not silently treat k as a universal constant. Report observed iterations and a rigorous stopping tolerance; exact finite termination in ideal arithmetic does not imply floating-point exactness.
- A residual tolerance can be translated into a ratio gap using a positive denominator lower bound. Handle all-zero prediction scores and empty unions separately, with the same convention as evaluation metrics.
- Compare efficiency to a properly implemented O(n²) breakpoint cumulative-sum/enumeration baseline, not only an O(n³) implementation that rescans every point for every threshold pair. At modest n, NumPy's quadratic baseline may be faster than Python tree operations.
- The exact minimum over the full rectangle is no larger than the minimum over its 15 sampled operators. Strict inequality is an audit finding, not proof of better physical labels.
- One shared operator across all panels must stay shared when a global metric is reported. Averaging separately minimized panel IoUs answers a different question. Likewise macro-averaging ratios is not the same fractional program as pooled IoU.
- A computationally certified minimum inside a chosen rectangle is **not a confidence bound for physical ground truth**. Membership of the unknown physical labeling rule in that rectangle remains an unverified modeling assumption.

## Minimum evidence for a substantive contribution

1. Exhaustive randomized/property tests against all breakpoint pairs, including ties, boundary-only optima, degenerate labels and fixed-mask exclusions.
2. A constructed coarse-grid failure plus observed frequency/magnitude of failures on every existing development panel and all declared models; retain null results.
3. Wall-clock and memory scaling against both exact enumeration and coarse grids at matched semantics; count fractional iterations and report achieved objective gaps.
4. Separate two questions: changed audit conclusions versus changed training. An exact evaluator can be worthwhile even when robust training does not outperform simple baselines.
5. Compare the uncertainty model explicitly with weak-supervision partial identification and adversarial label learning. Cite the old fractional and geometric algorithms rather than rebranding them.

A cautious claim would be: “We specialize established fractional and geometric optimization techniques to compute exact finite-sample sensitivity to globally shared threshold-based measurement operators, and demonstrate how coarse operator grids can alter scientific model comparisons.” The present search does not support a claim of first-ever exact Jaccard optimization or ground-truth-free validation in general.
