# 판정 규칙과 물리 경계의 식별 가능성 — 2026-10-21

최신 결과를 이미 본 뒤 정한 방법론 개발이다. 전향적 독립 확인이 아니다.

1. tilt_principle의 방향/중립점 주장을 수학적으로 검토하고 반례를 포함한다.
2. 물리학 및 통계의 선행 방법(선택/절단 편향, 오분류 민감도, 경계 추정)을 조사한다.
3. 단일 최고 지수 찾기를 중단하고, 판정 변경에 대한 법칙의 민감도 또는 식별 불가능성을 측정하는 한 가지 방법을 구현한다. 정확한 분석 목표와 평가 규칙은 실행 전에 추가 기록한다.
4. 작은 합성 문제의 참값/완전탐색 검증을 통과한 뒤 이미 노출된 실측 자료에 적용한다.
5. 이 자료에서의 재현, 계산상의 인증, 실제 물리적 진실을 분리한다. 새로운 법칙이나 성능 우위는 미리 약속하지 않는다.

기존 원자료·채점·다운로드 프로세스는 변경하지 않는다. 공유 논문 수정은 root만 수행한다.

## 실행 전 고정: 압축된 특징 모형으로 지수 변화 예측

기존 tilt 결과를 읽었으므로 아래는 사후 설명 모형의 반박 시험이다. 새로 쓴 계획을 커밋한다고 독립 확인 자료가 생기지 않는다. 데이터/기존 결과를 재채점하지 않고, 이미 보고된 변화와 새 모형 예측을 비교한다.

- 대상: 기존 표준 격자 14개 세션 중 D_T2는 window 축 1 mN 클램프 폭0 구간 때문에 주 분석에서 제외하고 이유/분모를 표시한다. B1 corner width는 단일 세션 보조 분석. 기존 저장 결과를 참조하며 원자료를 바꾸지 않는다.
- 특징: amplitude_std, flyback_height, periodicity, second_flyback_ratio. 별도 기준의 B1 corner width도 가능하면 포함. 기존 tilt 격자와 15% 제거를 고정한다. window 축을 주 분석으로 한다.
- M0: 기본 H 창에서 log X = 속도폴더 절편 + b log β + Gaussian residual.
- M1: 같은 모형에 log F_window를 추가. 계수와 잔차 분산만으로 가상 특징을 생성한다. 양의 유한 값만 특징 회귀에 사용하며 결측 처리는 원래 tilt 구현과 동일하게 한다.
- 같은 원래 H·β·힘 격자에서 각 모형의 가상 특징으로 15% 제거를 재현한다. 각 특징×세션 20회, seed=20261021. a별 같은 난수를 사용. K=2 경계와 독립 안정 검열 우도(verify_lower_law/statistics.py) 사용. 각 가상 적합의 폭0·미수렴·설계퇴화 비율 공개.
- 기존 관측 Δ 곡선과 예측 곡선의 MAE/RMSE, 중립점 오차, 주기성 ±0.2 결과, flyback ratio 중립점 미검출을 모두 보고한다. 예측 β 지수로 계수를 맞추지 않는다.
- 성공 기준: M1의 전체 Δ MAE가 0.15 이하이며 M0 대비 25% 이상 감소, 각 특징별 MAE도 0.25 이하. 모든 조건 충족 때만 '제한된 정량 설명 지지'; 아니면 부분 설명/실패. 이 기준은 이미 관측된 결과에 대한 설명력을 평가하며 외부 예측 성능이나 물리적 정답을 인증하지 않는다.
- 순서/β 교락, 기본 H 판정 자체의 오류, 임계값만으로 정해지는 꼬리 제거를 명시한다. 재생 모형은 새로운 실측 H를 발견하는 분류기가 아니다.

## 별도 이론 검토

고정 제거 수의 순위 이동에 대한 정리와, 경계 지수 단조성·a=b 중립점 주장에 필요한 추가 가정을 분리한다. 작은 합성 반례를 완전탐색/수식으로 검증한다. 기존 interval censoring/오분류 민감도 선행과의 차별점을 먼저 확인한다. 라벨 변경 인증 방법은 이번 단계에서 설계 검토만 하고 별도 대규모 격자를 추가하지 않는다.

## 보조 관측 고정: 제거 위치와 경계 영향

최대 힘 일반화 실패의 사후 진단으로, 같은 13세션·4특징·기존 모든 tilt·15%에서 제거되는 H가 원래 첫/마지막 K=2 묶음과 얼마나 겹치는지 계산한다. 아래/위 경계 끝점 변화율, 원래 H 묶음이 있던 열에서 묶음 소실 비율을 함께 공개한다. 새 지수 재적합이나 임계값 선택은 하지 않는다. 물리적 원인을 주장하지 않고 경계 추출 단계의 영향 경로만 확인한다.

## 실행 후 감사 수정 기록: 비교 마스크 일치

최초 고정 분석 완료 뒤 독립 검토에서 M1만 비양수 힘의 H 창을 회귀와 제거 자격에서 제외함을 발견했다. 총 4개 창(A2 1, B1 1, B_T2s1 2)이다. 두 모형의 차이를 log F 추가로 해석하려면 M0도 동일한 마스크로 비교해야 한다. 원래 결과는 보존하고 이 세 세션의 M0만 같은 유효 힘 마스크·같은 난수로 다시 계산한 민감도 결과를 별도 저장한다. 이는 새로운 후보 선택이 아니라 공정 비교 수정이다. 발견된 기존 우도 적합의 수치 오차도 원래 저장 목표와 안정 재적합 목표에 대한 점수를 모두 공개한다. 동결 확인 결과는 변경하지 않는다.
