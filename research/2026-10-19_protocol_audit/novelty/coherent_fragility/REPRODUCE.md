# 독립 복사본에서 전체 재현

`reproduce.py`는 새 폴더에 코드·작은 파생 입력·비교 기준을 복사한 뒤 합성 검증, 실측 전체 문턱 프로파일, 구조적 진단, 독립 실측 감사를 다시 실행한다. 원자료 재추출·다운로드·패키지 설치·GPU가 필요하지 않으며, 원래 결과 파일을 덮어쓰지 않는다.

## 실행

Python과 NumPy가 필요하다. 그림까지 만들려면 Matplotlib도 필요하다. 현재 연구 환경에서는 다음 명령을 사용할 수 있다.

```bash
/Users/jeongjihoon/violin-bowing-boundaries/.venv-mac/bin/python \
  /Users/jeongjihoon/violin-rne/novelty/coherent_fragility/reproduce.py \
  --figures
```

다른 컴퓨터에서는 이 폴더를 통째로 복사하고, 필요한 라이브러리가 있는 Python으로 실행하면 된다.

```bash
python reproduce.py --figures --output-dir /tmp/coherent-reproduction
```

출력 경로는 **새 폴더 또는 빈 폴더**여야 하고 원본 연구 폴더 내부일 수 없다. 생략하면 새 임시 폴더가 생성된다. 기존 결과가 들어 있는 폴더나 심볼릭 링크를 지정하면 거부한다. `--figures`를 생략하면 그림 생성만 건너뛴다. 단계별 제한 시간은 기본 600초이며 `--timeout-per-step`으로 조정할 수 있다. `--python`은 하위 계산용 인터프리터를 지정한다. 실행기 자체의 NPZ 비교에도 NumPy가 필요하다.

## 포함된 계산

1. 작은 합성 데이터에서 직접 분류·첫 연속 구간을 계산한 독립 기준과 전체 프로파일 및 최적값을 비교한다.
2. 잘못된 입력, 동일 점수의 동시 변화, 닫힌 범위와 무한대 끝점, 고정 분기 및 결측값을 검증한다.
3. 기록 극값에 따른 첫 연속 구간의 도달 가능성 공식을 독립 분류와 비교한다.
4. 파생 입력 78,000창의 식별자·힘·기존 라벨을 이전 단계의 보존된 입력과 대조하고 네 판정 규칙의 기준 문턱이 기존 라벨을 재현하는지 검사한다.
5. 여섯 규칙/범위 조합의 전체 문턱 프로파일과 모든 선언된 기울기·허용 오차 결과를 새로 계산한다.
6. 도달 가능한 경계와 전체 대상 집합의 무효화를 다루는 구조적 진단을 계산한다. 추가된 사후 진단의 성격은 해당 결과 문서와 동일하다.
7. 생산 sweep를 가져오지 않는 별도 코드로 저장된 실측 프로파일 전체, 공통 문턱 증거, 폴더별 최적값 및 비용 예산별 결과를 검증한다.
8. `--figures`이면 결과 그림 두 장을 새로 생성한다.

입력 `prior_input_columns.json.gz`는 이전 임의 라벨 변경 연구의 공개 원천 파생 fixture를 그대로 보존한 것이다. `input_features.json.gz`에는 새 분류에 필요한 수치 특징·고정 분기만 들어 있다. 원시 파형이나 대용량 압축 자료는 필요 없다. `arbitrary_reference.json`은 앞선 무제약 최솟값과의 하한 비교용이며, 이 재현 단계가 이전 무제약 알고리즘까지 다시 계산하지는 않는다. 그 계산은 별도 `run_fragility/reproduce.py`가 담당한다.

## 판정과 보존

출력 폴더에는 `work/`(계산 복사본), `reference/`(시작 시점 기준 결과), `logs/`, `reproduction_report.json`이 생긴다. 성공 조건은 다음과 같다.

- 모든 단계가 정상 종료한다.
- JSON의 과학적 필드와 값이 모두 일치한다. 최상위 실행 시간과 출처 해시만 비교 대상에서 제외하며, 제외 및 차이를 보고서에 표시한다.
- 여섯 NPZ의 모든 키·배열 형태·자료형과 원소를 비교한다. 정수·불리언은 정확히, 실수는 절대/상대 오차 각각 `1e-12` 이내로 비교하며 대응 NaN을 동일하게 취급한다. pickle은 허용하지 않는다.
- 원본 코드·입력·결과가 시작 시점 해시와 동일하고, 복사본의 입력도 변하지 않는다.
- 요청한 두 그림이 비어 있지 않은 PNG로 새로 생성된다. 운영체제별 글꼴·렌더링 차이 때문에 PNG 바이트의 일치를 요구하지 않는다.

프로파일 재현은 선택한 최적 사례만 비교하는 것이 아니다. **도달 가능한 모든 문턱 상태의 비용·무효·경계·양립 배열**을 비교한다. 다만 계산의 재현과 독립 구현 일치가 분류의 물리적 정확도, 기존 MLE 검정의 반전, 독립 데이터에서의 일반화를 입증하지는 않는다.

## 실제 재현 기록 — 2026-10-21

최종 실행 보고서: `/private/tmp/coherent-fragility-reproduction-20261021-final/reproduction_report.json`. 임시 폴더는 운영체제가 정리할 수 있으므로 연구 보관본에는 해당 보고서를 별도로 보존한다. 원본 폴더 내부·비어 있지 않은 폴더·파일·심볼릭 링크 등을 대상으로 한 5개 출력 경로 거부 검사도 통과했다.
