# 하나의 일관된 특징 문턱으로 법칙 양립을 바꾸기 — 실행 전 계획

2026-10-21. 모든 원자료와 앞선 지수·임의 라벨 최소 비용을 본 뒤의 **사후 방법 개발**이다. 이 규칙의 정확 비용·양립 결과는 아직 계산하지 않았다. 공개 사전등록/독립 확인으로 부르지 않는다. 기존 원자료·라벨·동결 채점·파이프라인은 수정하지 않는다.

## 질문과 고정할 결정

같은 하나의 숫자 문턱을 모든 78,000개 창에 적용해, 한 속도 폴더의 모든 대상 첫 K-run 경계가 `log F = a + p log beta`와 양립하도록 만들 수 있는가? 법칙 절편 a는 폴더마다 자유롭지만 **판정 문턱은 폴더·세션·beta·힘에 따라 달라지지 않는다.** 새 분류기는 힘, beta, 속도, 세션 ID를 입력으로 사용하지 않는다. 같은 데이터로 문턱을 고르는 민감도 분석이며 분류의 정확도를 높이는 학습은 아니다.

앞선 run_fragility와 같은 13도표·39폴더·원래 유한한 양의 K=2 아래 경계 1,132열·56,600창, p=−2와−1.2, epsilon=.2 자연로그 힘. 원래 왼쪽 검열315열/no-run113열은 결정 제약에서 제외하되 **판정 규칙과 전체 변경 비용은 제외 열에도 적용한다.** 변경 후 한 대상 열이라도 유한한 양의 경계를 잃으면 해당 폴더는 성공으로 세지 않고 무효로 따로 센다. 대상 집합을 변경하지 않는다. 이 새 모든-열 구간 양립 결정은 기존 MLE 검정이 아니다.

## 규칙군 — 한 번에 특징 하나, 문턱 하나

1. **periodicity:** 기존 periodicity >= .8을 >= t로 바꾼다. 다른 분류 조건 고정. 주 범위 t∈[.7,.9].
2. **second_flyback_ratio:** 기존 ratio < .5를 < t로 바꾼다. 다른 분류 조건 고정. 주 범위 t∈[.3,.7].
3. **amplitude:** 기존 H에 amplitude_std >= t를 추가한다. t∈[0,+∞]. 원래 문턱은 t=0이며 값이 음수/비유한인 원래 H가 있으면 감사 후 명시적으로 처리하며 조용히 제거하지 않는다.
4. **flyback_height:** 기존 H에 flyback_height >= t를 추가한다. t∈[0,+∞]. 위와 같은 결측 감사.

periodicity/ratio 주 범위는 이전 분석에서 이미 사용한 변화 범위를 채택했다. 별도 민감도로 두 특징 각각 [0,1] 전범위를 계산한다. 이것도 물리적으로 타당한 판독 기준이라는 보장은 없다. amplitude/height의 전범위는 특히 허용 오차 교정이 없는 스트레스 시험이다. 이 결과를 좁은 두 규칙의 결과와 분리해 보고한다. 결측 특징은 새 기준의 증거가 아니므로 변경하지 않고 원래 라벨을 유지한다. 유한 값의 나머지 guard는 기존 분류기와 일치시킨다. 원래 t에서 이전 fixture 78,000개 라벨과 일치해야 본 계산을 진행한다.

네 특징을 조합하거나 beta 기울기를 추가하지 않는다. 그런 결과의존적 확장은 별도 계획이 필요하다. 기울기나 측정 힘을 직접 사용하면 원하는 법칙을 분류기에 넣을 위험이 있어 이번 질문에서 제외한다.

## 정확 계산과 비교

같은 수치 특징이 있는 모든 창은 동시에 변한다. `>= t`와 `< t`의 동률·닫힌 범위를 정확히 처리한다. 라벨이 변하는 모든 특징값 사건과 양옆 구간을 열거하고 변경된 열의 첫 K-run을 갱신한다. 각각의 패턴에서 각 폴더의 전체/대상 창 변경 수, 변경된 대상 beta열 수, 무효열 수, 절편 교집합과 지수별 양립 여부를 보존한다. 원래 라벨은 덮어쓰지 않는다.

- **폴더별 oracle:** 각 폴더를 개별 최적화했을 때 양립 가능한 문턱 구간과 대상 창 최소 변경 수. 전체 데이터에서 하나의 문턱을 썼다는 결과와 구별한다. 앞선 임의 변경 최소 비용보다 작을 수 없다. amplitude/height에는 삭제 전용 하한도 비교한다.
- **공통 규칙 주 결과:** 특징 하나의 동일 문턱을 39폴더 전체에 적용한다. 복원 가능한 폴더 수를 최대로 하되 동률이면 전체78,000창 변경 수 최소, 이후 기준 문턱에 가까운 패턴, 이후 문턱 증가 순서로 정한다. 전체39폴더의 동시 양립 여부도 명시한다. −2는 앞선 격자 제한만으로 상한14/39이므로 달성률의 분모를 숨기지 않는다.
- **비용–복원 곡선:** 전체 창 예산 1%,5%,10%,15%,30%,100%에서 최대 복원 폴더 수를 보고한다. 성공뿐 아니라 무효가 된 폴더/열과 전체 변경 비용도 공개한다. 원래 제약 밖 창의 변경은 부수 비용으로 분리한다.
- **epsilon 민감도:** 0,.1,.2,.4에서 동일 라벨 패턴을 재평가한다. 원래 양립하는 경우와 복원 비용0을 결정 반전으로 혼동하지 않는다. 이번 주 데이터는 eps.2에서 원래 모두 불양립이다. K=2 고정으로 새 K 선택을 하지 않는다.
- 개별 최적문턱을 모아서 하나의 공통 규칙처럼 표시하지 않는다. 여러 규칙 중 좋은 것만 골라 일반 성능을 주장하지 않는다. 모든 규칙과 실패를 공개한다.

## 독립 검증·재현

작은 합성 격자에서 모든 동률 특징값·사이 구간·범위 끝점의 라벨을 처음부터 계산하는 독립 코드와 생산 sweep의 전체 패턴 비용·무효·절편·양립을 비교한다. K1–3, 양쪽 부등호, 결측 고정, 공유 문턱 불가능하지만 개별 문턱 가능한 경우, 점 경계, 빈 guard를 포함한다. 증명은 라벨 패턴이 사건 사이에서 일정하고 모든 사건을 방문한다는 완전성이다. sweep 자체는 기존 방법이다.

실측 feature fixture를 기존 run_fragility 입력과 창ID·힘·beta·원래 라벨까지 일치 확인한다. 최적 문턱은 독립 코드로 전체 창에 재적용하고 모든 결과를 다시 검사한다. 최소 비용 하한과 비교한다. 합성/실측 입력·결과·원본 해시와 복사본 재현 실행을 보존한다. 최솟값이 나와도 실제 라벨 오류나 물리 법칙의 진실, 외부 예측 개선을 뜻하지 않는다.

## novelty 후보와 판단

일반 문턱 sweep, multiverse/fragility 개념은 선행이 있다. 기여 후보는 **판정 규칙이 창들을 함께 바꾸는 제약을 정확히 반영하여 경계 법칙의 민감도를 인증하고, 임의 라벨 편집 하한과 실제 공통 규칙의 비용·달성 불가능·부수 영향을 연결하는 것**이다. 성공 여부를 보장하지 않는다. 일관된 규칙으로 불가능하다는 결과도 앞선 임의 편집이 얼마나 비현실적인지 구분하는 의미가 있다. 이 규칙군 안의 불가능은 모든 가능한 분류기의 불가능이 아니다.
