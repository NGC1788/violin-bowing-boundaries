# Exact first-run attainability under one scalar gate

2026-10-21. An elementary structural derivation for the declared classifier family; not a claim to a new general theorem. The derivation supplies an independent interpretation of the threshold sweep. It does not use empirical results.

## Decreasing positive acceptance: score >= threshold

At a fixed force-ranked column, let each label be

`H_i(t) = g_i AND [z_i >= t]`,

where the fixed gate g_i includes all predicates that do not vary with the threshold. Thresholds t are finite and lie in the declared domain. Missing or otherwise rejected features are represented by g_i=false, not an invented score.

For each possible K-run start s define its activation score

`q_s = min(z_s, ..., z_(s+K−1))` if every gate in that window is true, and `q_s = −∞` otherwise.

That window is all H exactly when `t <= q_s`. It is the *first* K-run exactly when every earlier candidate window is not all H. Hence

`first_run(t)=s  <=>  max_{r<s} q_r < t <= q_s`.

The empty prefix maximum is −∞. The threshold interval must then be intersected with the declared parameter domain. A candidate can be reached only if q_s is a **strict record high** among activation scores. Equal scores do not create an extra realizable state: the earlier run wins. A missing run occurs when `t > max_s q_s`.

This result is about windows along increasing force, not time windows along a stroke. It applies to a periodicity acceptance floor and to baseline-H plus an amplitude or flyback-height floor, when their other gates are fixed.

## Increasing positive acceptance: score < threshold

For `H_i(t) = g_i AND [z_i < t]`, define

`q_s = max(z_s, ..., z_(s+K−1))` if every gate is true, and `q_s = +∞` otherwise.

The first K-run condition becomes

`first_run(t)=s  <=>  q_s < t <= min_{r<s} q_r`.

The empty prefix minimum is +∞. Only **strict record lows** are attainable first-run positions. A missing run occurs for `t <= min_s q_s`. This case corresponds to the strict second-flyback-ratio ceiling in the declared rule. The inequality closure differs if the classifier uses <= instead of <; it must follow the implementation literally.

## Consequence for the boundary-law problem

Each attainable finite-positive start s already has a log-force intercept interval

`J_s(p,epsilon) = [log F_(s−1) − p log beta − epsilon, log F_s − p log beta + epsilon]`.

Its admissible parameter/physical-boundary pairs form a rectangle

`T_s × J_s(p,epsilon)`,

where T_s is the threshold interval from the record envelope above. The force-grid-only problem used all finite-positive starts, while a coherent scalar rule admits only the strict records and ties their selections across all columns through the same t. These are two distinct restrictions:

1. **Within-column attainability:** a non-record first boundary cannot be generated by that scalar rule, even if arbitrary edits reach it cheaply.
2. **Between-column coherence:** individually attainable boundaries may demand disjoint threshold intervals, so no one common threshold can realize the proposed collection.

At any threshold t, every column has a unique first-run state or an invalid state. The folder is law-compatible iff all fixed columns have allowed finite states and the corresponding J intervals share an intercept. This is why an exact threshold sweep suffices and why independent per-column DP choices are a relaxation.

The same threshold additionally applies to other folders. Each folder may profile its own intercept, but it cannot choose its own classifier threshold when making a simultaneous-coverage claim.

## Appropriate claim

“Threshold coherence imposes an explicit attainability restriction: only record extrema of K-window scores can become first-run force boundaries, and their threshold intervals must agree across columns. We use this structure to distinguish unrestricted label sensitivity from changes induced by a shared waveform criterion.”

This is a transparent structural certificate for the chosen family. Record statistics, sliding extrema and parameter sweeps are established tools. Its research value depends on what it reveals about this data and pipeline, not on relabeling elementary order-statistic algebra as a novel optimization breakthrough.
