# 서면 방법론 선택 범위

- AI 학습 방법과 실제 미래 예측이 목표이며 현재는 서면 검토 한 단위다.
- 공개 집계·기존 코드·직접 선행 원문만 읽는다. 실제 원음/NPZ/행별·개인별 정답/가중치 접근·hash, fitting/forward, 다운로드, standalone 수치 감사를 하지 않는다.
- 최대3후보·후보당 직접선행2개를 비교한다. 기존 캠페인/기준을 변경·재실행하거나 단순 결함 수정에 novelty를 붙이지 않는다.
- 기존 결과를 보존한다. 채택은 최대1개이며 학습 허가가 아니라 별도 코드 준비의 근거다.
- 별도 방법 검토는 기존 공동 검토자에게 위임해 독립적인 반박을 받는다. 검토자는 이 범위에서만 읽고 쓰며 실제 자료를 열지 않는다.
- 코드/문서/집계/해시만 허용 브랜치에 공유하고 모든 실제 자료와 계정정보를 비공개로 유지한다.
