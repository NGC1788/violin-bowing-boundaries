# 공개 바이올린 자료 적합성 관문

확인일: 2026-10-30. 네 개 자료 계열의 제작자·기관 공식 공개 경로만 표적으로 조사했다. 전체 공개 데이터 조사나 다운로드·실험 완료가 아니다. 대용량 자료는 받지 않았으며, API 메타데이터와 작은 CSV 헤더만 확인했다.

**결론:** 현재 첼로 힘 경계를 바이올린에서 검증할 수 있는 자료는 이 네 후보에서 확인하지 못했다. 바이올린 예측 연구로 확장할 현실적인 후보는 있지만, 지금 바로 “바이올린 외부 검증 준비 완료”라고 할 수는 없다. 가장 작은 원시 오디오+동작 후보는 Wilson 2025이고, 명시적 공개 라이선스가 확인된 후보는 Blanco 2021이다. 둘의 남은 조건이 다르다.

## 1. Wilson 2025: 오디오와 스마트워치 동작 — 기술적 1순위, 라이선스 관문

[제작자 저장소](https://github.com/willfwilson/smartwatch-based-audio-gestural-insights-in-violin-bow-stroke-analyses)에 실제 Participant01–09 폴더가 있다. 공식 GitHub tree API로 **M4A 108개, CSV 216개, README 1개**, 전체 파일 합계 **147,021,012 bytes**를 확인했다. 예시 경로는 `Participant01/Legato/1_GMaj/Take1/`이며 `Spiccato` 폴더도 있다. 단순한 자료 소개 페이지가 아니라 다운로드 가능한 개별 오디오·가속도·자이로 파일이다. 가속도 CSV의 첫 1,800 bytes만 읽어 `time,x,y,z` 헤더와 시간별 값을 확인했다. 시간 정렬의 정확성은 아직 검증하지 않았다.

**라벨:** 확인한 것은 폴더 수준 주법·음계·take·참여자 구분이다. 활 힘, β, 헬름홀츠 정답, 전문가 음질 점수가 있다는 근거는 없다. 같은 take 전체에 고정된 Legato/Spiccato를 잘라 미래 주법 예측이라 부르면 과제가 쉽게 퇴화한다.

**권리:** root/재귀 tree에서 LICENSE가 없고 공식 `/license` API도 404다. 논문 공개 라이선스가 원자료에 자동 적용된다고 가정하지 않는다. README는 짧은 자료명뿐이므로 사용·파생물 배포 조건은 아직 확인되지 않았다. 저자에게 연락하지 않았다. [공식 파일 목록 API](https://api.github.com/repos/willfwilson/smartwatch-based-audio-gestural-insights-in-violin-bow-stroke-analyses/git/trees/main?recursive=1)

판정: **접근·용량·실제 신호 존재는 확인, 권리와 동기화가 해결되면 작은 파일럿 가능.** 현재 자동 학습 분기에는 넣지 않는다.

## 2. Blanco·Tassani·Ramirez 2021: 소리·동작 피드백 시험 — 권리 확인, 내용 관문

[제작자 Zenodo 레코드](https://zenodo.org/records/4554201)는 `Sound_and_Motion_Data.rar` **468,988,201 bytes**와 md5 `352be95f849ebeeb76a3cc5e761208e7`을 제공한다. [공식 API](https://zenodo.org/api/records/4554201)에서 라이선스 **CC-BY-4.0**을 직접 확인했다.

설명에는 참가자별 raw sound/motion MATLAB 자료, bow-skew·dynamic-instability·pitch-instability 처리 코드, 집단·조건별 통계가 있다. 다만 **WAV 파일은 포함되지 않는다고 명시**한다. raw라는 단어만 보고 마이크 파형이 있다고 판단하면 안 된다. 압축파일 내부를 읽지 않았으므로 MATLAB 객체의 호환성, 연속 시간축, 미래창을 만들 수 있는 해상도, 참가자 수와 결측은 미확인이다.

판정: **공개 사용 조건은 네 후보 중 가장 명확하다.** 다음 허용 단계는 이 단일 469 MB 파일의 다운로드·MD5 검사·파일 목록/스키마 검사다. 연속 시계열이 실제 보존돼 있으면 초기 동작·음향 지표로 미래 불안정을 예측하는 후보가 된다. 조건별 평균만 분석 가능한 구조이면 시간 예측 분기를 종료한다. 기존 집단 효과를 다시 맞히는 것을 새 AI 성과로 만들지 않는다.

## 3. URMP: 연주 음원·음높이·음표 — 주석은 적합, 현재 다운로드/권리 미확인

[University of Rochester 공식 페이지](https://labsites.rochester.edu/air/projects/URMP.html)와 [4쪽 공식 문서](https://labsites.rochester.edu/air/projects/URMP/URMP_doc.pdf)를 확인했다. 44곡의 분리 악기 WAV, 합성 합주 영상, MIDI, 음표 onset/pitch/duration, 46 ms 창·10 ms hop의 음높이 주석이 있고 바이올린 트랙이 명시돼 있다. 정렬된 음표·음높이 예측에는 유용하다. 다만 합주가 따로 녹음한 연주를 조합한 것이므로 실제 상호작용 예측 자료로 취급하지 않는다.

페이지의 전체 패키지는 12.5 GB이며 링크는 현재 Google Form으로 연결된다. 공식 예제 ZIP 링크는 이번 확인에서 **404**였다. 공식 페이지/문서에서 적용 라이선스 문구를 찾지 못했고, 실제 전체 파일 접근을 확인하지 않았다. 등록 요청이 반드시 승인 절차라는 뜻까지는 추론하지 않는다.

판정: **실제 주석 정의는 확인했으나 바로 다운로드 가능한 검증용 자료로 확정하지 않는다.** force/β/H 판정은 없다. 사용 가능해지면 causal pitch/note forecasting을 검토할 수 있지만 전사와 음악 예측 선행연구가 풍부하므로 바이올린이라는 이유만으로 신규성이 생기지 않는다.

## 4. SyncViolinist, WACV 2025: 정밀 연주 동작 — 요청 기반 접근

[저자 공식 저장소](https://github.com/Kakanat/SyncViolinist)는 오디오에서 활·운지 정보를 거쳐 연주 동작을 생성하는 코드와 자료 구조를 공개한다. `aud`, `joint_aligned`, `pp_one_hot`, `wav_normalized` 등의 train/validation/test 구성이 명시돼 있다.

그러나 README는 데이터와 사전학습 모델 접근을 **저자에게 이메일로 요청**하도록 안내한다. 바로 받을 수 있는 데이터 링크가 아니다. 저장소의 라이선스 API는 404였고 데이터 사용 조건도 README에서 확인하지 못했다. 어떠한 이메일도 보내지 않았다.

판정: 동작 예측과 독립 모션 주석에 적합할 가능성은 있지만 **현재 무인 실행 자료로는 제외**한다. 기존 연구가 이미 audio→motion 학습을 제안했으므로 그대로 재현하거나 모델 이름만 바꾸어 신규 연구라고 할 수 없다.

## 실행 가능한 후속 질문과 중단 규칙

새 연구 질문 후보는 **“바이올린 연주의 짧은 과거 오디오·동작으로 가까운 미래의 음높이/진폭 불안정 확률을 예측하되, 판정 문턱이 달라져도 예측의 논리적 일관성을 유지할 수 있는가?”**다. 미래 신호의 기술적 불안정 지표를 목표로 하며, 좋은/나쁜 연주나 전문가 평점과 같다고 주장하지 않는다. 기존 첼로 연구와 공통점은 관측 규칙의 불확실성이고, 활 힘 법칙의 외부 검증은 아니다.

조건부 우선순위는 다음과 같다.

1. **Blanco 자료의 연속 시간 구조 확인**부터 한다. 이미 확인된 라이선스와 유한한 다운로드 크기 덕분이다. 시간축이 없으면 평균값으로 미래 예측을 꾸미지 않고 종료한다.
2. **Wilson 자료는 데이터 사용 조건 확인 후** 소수 take로 동기화·결측·단위·클리핑을 검사한다. 공개 파일 접근 자체를 학습·재배포 허가로 대신하지 않는다.
3. 미래 200 ms 위험 예측 같은 목표·원점·예산은 검사 뒤 **점수 보기 전에** 고정한다. sound/motion이 시간 정렬되지 않으면 다중모달 목표를 중단한다. 변화가 거의 없으면 persistence가 이미 해결하는 과제인지 먼저 검사한다.
4. 참여자 전체와 take를 그룹으로 분리한다. 겹치는 창 무작위 분할 금지, 절대시각·파일명·참여자 ID·미래 정규화 통계 입력 금지. 9명은 9명이며 수천 창을 수천 독립 연주자로 세지 않는다.
5. persistence/AR, 음향 특징 HGB, 오디오만 쓰는 작은 TCN, 동작만 쓰는 모형, 단순 late fusion이 기준선이다. 일관된 미래 확률 모형의 이득을 독립 head와 사후 단조 보정에 대조한다. 동작을 학습에만 쓰는 distillation도 기존 기술이므로 그 자체를 신규성으로 부르지 않는다.
6. 미래 지표 예측에 실제 이득이 없거나 독립 참여자에서 무너지면 바이올린 분기를 종료한다. 별개 과제의 성공으로 첼로 힘 경계의 타당성을 대신 증명하지 않는다.

**현재 허용되는 보고:** “신규 측정 없이 사용할 수 있는 바이올린 자료 후보 네 계열을 조사했고, 데이터 접근·라이선스·시간축의 관문을 정했다.” **아직 허용되지 않는 보고:** “바이올린 외부 검증 확보”, “바이올린 활 힘 경계 확인”, “최신 바이올린 AI 성능 개선”.
