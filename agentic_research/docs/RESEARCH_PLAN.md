# AI 중심 후속 연구 계획 — 2026-10-30

## 1. 현재 성과와 새 질문

기존 연구는 공개 첼로 자료의 판정 선택이 활 힘 경계와 법칙 추정에 미치는 영향을 정확하게 계산했다. 동적계획·구간 계산·최소 모순 설명은 정보과학 내용이다. 다만 새 학습 방법과 독립 조건의 성능 개선이 핵심 성과로 확립되지 않았으므로, AI 연구라는 설명에는 부족함이 있었다.

후속 연구 질문은 다음과 같다.

> 이미 기록된 활현 파형에서, 학습 모델이 필요한 파형을 먼저 선택하도록 하여 여러 판정 규칙의 경계를 더 적은 파형 확인으로 정확히 알아낼 수 있는가?

제안 제목은 **「학습된 관측 선택과 정확 인증을 결합한 판정 규칙별 신호 경계의 능동 복원」**이다. AI는 관측 순서의 효율을 담당하고, 별도의 정확한 알고리즘은 종료 시 경계의 일치를 확인한다. 틀린 prior는 질의를 늘릴 수 있지만 인증 결과를 바꿀 수는 없어야 한다.

## 2. 문제 정의와 비용

각 조건에는 실측 힘순으로 정렬된 서로 다른 파형 50개가 있다. 위치 i의 파형을 확인하면 선언한 규칙 9개의 라벨 벡터를 얻는다. 목표는 각 규칙에서 처음 K=2개의 연속 H가 나타나는 시작점이다. 시작점이 0이면 관측 격자 아래쪽 검열에 해당하며, 묶음이 없으면 별도의 no-run 범주다. no-run을 물리적 우측 검열의 증명으로 해석하지 않는다.

파형 한 개를 질의하면 9개 규칙 결과를 함께 얻으므로 비용은 9가 아니라 1이다. **힘·속도·접촉 위치는 기존 측정의 공개 메타데이터**다. 미질의 periodicity, ratio, guard, fixed, H는 선택기에서 숨긴다. 실제 힘순서를 이미 알고 있기 때문에 새 로봇 실험의 횟수 절감이 아닌 기존 기록의 선택적 파형 처리·감사 문제다.

주 지표는 9개 규칙 모두를 인증할 때까지 필요한 파형 수다. 평균·중앙값·90백분위·최대·그룹별 수치를 함께 기록한다. 예산 5/10/20/35/50에서 경계 위치 오차와 인증률도 기록한다. 비교 모델이 미결일 때 해당 열을 평균에서 빼지 않는다.

저장된 JSON을 읽는 실험에서 질의 수는 비용의 대용치다. 실제 특징 추출 또는 사람이 확인하는 시간이 충분히 크다는 측정 없이 wall-clock 가속이나 노동 절감을 주장하지 않는다. 학습과 선택기의 실행 시간을 따로 보고한다. 기준선보다 Q개의 파형을 줄이고 선택기 시간이 T초 늘었다면, 질의당 실제 비용이 T/Q초보다 커야 총 시간이 줄어든다. 학습 비용은 별도로 포함하거나 명시적으로 상각한다.

## 3. 학습과 정확 계산

prior는 공개 좌표 x_i=(log F_i, log beta_i, log v_i)와 규칙 문턱을 이용해 각 라벨의 확률을 예측한다. 표본 가족 A/B만 학습에 쓰며, 전처리도 학습 부분에서만 적합한다. 모델은 상수 prevalence, 로지스틱, HGB, 작은 MLP를 비교한다. 고정 0.5 prior는 상수 prevalence와 별개다.

라벨이 조건부 독립 Bernoulli라고 근사하면 첫-run 분포를 유한상태 동적계획으로 정확히 전파할 수 있다. a_i(r)는 앞 i개에서 아직 run이 없고 마지막 연속 1 길이가 r<K인 확률이다.

\[
a_i(0)=(1-p_i)\sum_{r=0}^{K-1}a_{i-1}(r),\qquad
a_i(r)=p_i a_{i-1}(r-1).
\]

위치 i에서 첫 run이 완성될 확률은 p_i a_{i-1}(K-1)이다. 마지막 생존 질량은 no-run 범주로 간다. 이 전파의 정확성은 독립 prior 모형 안에서의 계산 정확성이다. 실제 파형 사이의 독립성이나 확률 교정까지 보장하지 않는다.

질의 후보를 0/1로 각각 조건화해 첫-run 엔트로피 감소의 기대값을 구한다. 한 파형을 공유하는 규칙들의 **주변 정보이득 합**을 최대로 하는 위치를 선택한다. 규칙 9개의 상관을 모두 모델링한 정확 공동 엔트로피라고 부르지 않는다.

MLP 제거 실험은 같은 입력·크기·초기 시드·열 단위 배치·학습 횟수를 유지하고, BCE만 학습한 모형과 BCE+첫-run categorical NLL을 학습한 모형을 비교한다. 구조화 손실이 실제 인증 질의 감소로 이어지는지가 검증 대상이다. 손실을 붙였다는 사실 자체는 성능이나 novelty 증거가 아니다.

## 4. 종료 인증

부분 관측에서 모르는 라벨을 모두 1로 채운 시작점은 가능한 가장 이른 시작점이고, 모두 0으로 채운 시작점은 가능한 가장 늦은 시작점이다. 둘이 같으면 모든 중간 완성이 같은 값을 갖는다. 규칙별로 이 조건이 성립해야 공동 인증을 선언한다.

이론은 힘에 따른 H의 단조성을 가정하지 않는다. H 띠, 중간 구멍, 여러 묶음과 미검출을 모두 허용한다. 50개를 전부 확인하면 반드시 인증되어야 한다. 높은 예측 확률을 이유로 검사를 생략하지 않는다. 실행 한도에 도달한 작업은 성공으로 채점하지 않고 실패·중단으로 보존한다.

검증은 짧은 모든 이진열과 부분 마스크를 전수 열거하여 DP 분포, 조건부 정보이득, 인증을 독립 계산과 비교한다. 0·1 극단 확률, no-run, 맨 앞 run, 뒤쪽 run, 혼합 규칙, 중복 질의도 검사한다.

## 5. 강한 기준선과 진단

| 비교 | 목적 |
|---|---|
| 전체 50개 | 항상 정확한 참조 비용 |
| 앞에서부터 | 경계가 앞에 있을 때 강한 기준선 |
| 짝수 위치 우선, 이어 홀수 | K=2 창을 적은 0 관측으로 배제하는 구조적 기준선 |
| 무작위 | 선택을 학습하는 이득의 기준 |
| 0.5 prior + DP 정보이득 | 학습 없이 구조만 이용한 효과 |
| 학습 prevalence + DP | 입력 없는 라벨 통계의 효과 |
| HGB + 점별 불확실성 | 동일 학습 모형에서 획득 목적만 제거 |
| 로지스틱/HGB/MLP + DP | prior 표현력과 학습의 기여 |
| 같은 MLP의 BCE 대 BCE+run NLL | 구조화 학습의 추가 기여 |

실제 라벨을 모두 본 뒤 최소 인증 크기도 계산한다. 유한 첫 시작점의 K개 1과, 더 이른 모든 K창을 가리는 최소 0 집합이 필요하다. 1차원 구간의 오른쪽 가능한 0을 고르는 greedy를 작은 전수 최적화와 비교한다. 여러 규칙에서는 각 최소값의 최댓값이 유효한 하한이며 공동 최적값이라고 주장하지 않는다. 이는 정답을 본 뒤의 oracle 하한이므로 배포 가능한 비교 모델이 아니다.

후속 기준선은 작은 문제의 최적 적응 정책, EC2/ECED 계열, GP level-set/straddle이다. 아직 구현하지 않은 것을 구현·비교 완료라고 쓰지 않는다. 새 정책이 기존 entropy heuristic의 적용에 그친다면 그 범위만 주장한다.

## 6. 데이터와 평가 범위

입력은 기존 `novelty/joint_rule/input_joint.json.gz`의 1,560열·78,000파형이다. family A/B를 학습, C1/C_T2/D1/D2를 개발 평가로 둔다. 같은 현 유형의 일부 세션이 학습과 평가에 섞이지 않게 가족 단위로 나눈다. 각 50개 힘순열은 분할하지 않는다. 개별 규칙 9개를 독립 물리 표본으로 세지 않는다.

첫 파일럿은 네 개발 도표에서 고정 시드20261030으로 같은 16열을 고른다. 후보 학습 시드가 달라도 평가 열은 같다. 이 단계는 구현·비용·초기 경향 확인용이며 성능 결론을 확정하는 실험이 아니다.

모든 원자료는 과거 연구에서 이미 노출되었다. 새 모델이 개발 라벨을 학습하지 않는다는 것과 연구자가 그 자료를 본 적 없다는 것은 다르다. 새 시드나 교차검증으로 과거 노출을 지우지 않는다.

다음 단계는 후보를 먼저 고정하고 전체 개발 480열, 같은 시드0/1/2, 모든 방법의 같은 평가 열을 비교하는 것이다. 주 비교는 가장 강한 비학습 기준선 대비 인증 오류0인 상태에서 평균 질의 수10% 이상 감소다. 10%는 운영상 승격 기준이며 통계적 정리·보장된 달성값이 아니다. 그룹별 악화·선택 overhead를 함께 판단한다. 창 단위 p값이나 시드 수만으로 모집단 신뢰구간을 만들지 않는다.

새 데이터에서의 일반화 주장은 별도의 미사용 외부 benchmark나 새로 얻은 데이터로 확인해야 한다. 현재 보고서는 탐색적 개발 결과다. 바이올린 실측 검증이나 음질 향상으로 바꾸어 쓰지 않는다.

## 7. 새로움의 범위

직접 선행은 EC2/ECED, stochastic Boolean function evaluation, active feature acquisition, level-set estimation, differentiable DP다. 정확 종료·정보이득·학습 prior·자동 연구 에이전트는 개별적으로 새 발명이 아니다.

후보 기여는 비단조 first-K-run·검열이라는 구조, 공통 판정 규칙의 공유 질의, 경계 목적 학습을 결합해 얻는 계산·질의 효율이다. 좋은 실증과 가장 가까운 기존 방법 비교, 명확한 비용 모델이 있어야 기여가 된다. 최신 모델 이름을 붙이는 것으로 정보과학 기여를 대신하지 않는다.

최신 문헌의 검토 범위와 채택·보류 근거는 `LITERATURE_REVIEW.md`에 있다. 이론 전체를 검증한 문헌과 초록만 확인한 문헌을 구분했다.
