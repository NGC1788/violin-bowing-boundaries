# AI 연구의 다음 의사결정 — 2026-10-30

> 보존된 설계 검토 의견이다. 아래의 random3seed/최종후보1개 권고와 실제 채택한 v2 규약을 구분한다. 실제 동결은 기준선5개(seed0)와, 관문 통과 시에만 학습비교5개×3seed였다. 전체480열의 개선 상한5.83%가 확인되어 기준선5개 뒤 종료했다. 학습 비교는 실행하지 않았다. 실제 계약은 `engine_v2/configs/development480_v2.json`, 결과는 `FULL480_RESULTS.md`다.

이 문서는 다음 단계의 설계안이다. 고정 하네스·평가 기준·실험 결과를 변경하지 않았고, 480개 개발 열을 새로 분석하지 않았다. 현재 연구의 결론과 새 AI 연구의 성공 여부를 구분한다.

## 1. 현재 결론: AI를 더 붙이기 전에 개선 가능량부터 확인한다

현재 계산 연구에는 실제 내용이 있다. 첫 연속 성공 경계의 정확한 인증, 최소 판정 변경, 공통 규칙의 모순 탐색은 정보과학 방법이다. 그러나 학습 모델의 실질적 이득은 아직 입증되지 않았다. 자동화 루프 자체를 AI 방법론의 신규성으로 내세우면 이 간극이 해결되지 않는다.

고정된 16개 열에서 uniform-entropy는 평균 12.0625개 질의로 정확한 답을 얻는다. 독립 검증한 **공동 최소 인증서**는 평균 11.125개다. 따라서 어떤 정확 인증 정책도 이 기준선을 7.77%보다 많이 개선할 수 없다. 계획의 10% 개선 조건은 이 파일럿에서는 불가능하다. HGB-entropy의 12.5625개는 오히려 기준선보다 나쁘다. 다른 학습기의 실행 중 결과와 관계없이 이 수학적 상한은 같다. [감사 보고서](independent_audit/SCIENTIFIC_AUDIT_20261030.md)

10%를 사후에 5%로 바꾸거나, 강한 기준선을 빼거나, 성공한 열만 고르면 안 된다. 파일럿은 “구현·정확성 검증 성공, 목표 성능 개선 불가능”으로 기록한다. 정답 인증은 안전장치이며, 학습기의 우수성을 뜻하지 않는다.

## 2. 다음 한 번의 관문: 전체 개발 자료의 개선 여지

다음 계산을 실행하기 전에 별도 프로토콜 JSON과 해시를 고정한다. 이름은 **개선 여지 진단**으로 하며, 새 미노출 확인시험이라고 부르지 않는다. 모든 측정 계열은 이미 과거 연구에서 노출됐다.

1. 480개 C/D 개발 열의 명단, 기존 16개 파일럿 포함 여부, 9개 규칙, K=2, 질의 단위, 공개 정보, 정확 종료 조건을 고정한다. 전체 480개와 파일럿을 제외한 464개를 별도로 보고한다.
2. 비교 정책은 기존 ascending, parity, uniform-entropy, random의 고정 3개 seed로 제한한다. source-prevalence 정책도 별도 단순 기준선으로 남긴다. baseline 선택 규칙은 결과 전에 고정한다.
3. 독립 참조기로 각 열의 정확한 공동 최소 인증서 크기 C*를 계산한다. 최강 비학습 기준선의 평균 질의를 B라 하면 개선 상한은 U=1−mean(C*)/B다. 오라클은 전체 답을 미리 아는 하한이지 실제 배포 가능한 정책이 아니다.
4. **U<10%이면 정확 질의 수를 주 지표로 하는 학습 연구를 종료한다.** 네트워크 크기·학습 시간·탐색 횟수를 늘려도 목표가 불가능하다. U≥10%는 필요조건일 뿐, 학습 개선 가능성을 보장하지 않는다.
5. 가능성이 남으면 파일럿 종료 시 이미 고정한 최종 후보 하나와 필수 ablation만 3개 seed로 평가한다. 480개 결과를 보고 새 후보를 계속 고르지 않는다. 후보 선택은 이 진단 결과를 보기 전에 고정한다.
6. 전체 평균, 각 측정 계열, 질의 90백분위, 인증 오류, 학습·획득 시간을 모두 공개한다. seed나 중첩 창을 독립 악기로 취급하지 않는다. 평균 10% 달성만으로 외부 일반화를 주장하지 않는다.

이 문제의 비용은 이미 기록된 신호의 판독 비용이다. 실측 힘과 정렬 순서를 입력으로 쓰므로 물리 실험 횟수 절감이 아니다. 실제 신호 한 개의 읽기·특징 계산 비용을 c, 추가 정책 비용을 ΔT라 하면 절약 질의 수 ΔQ에 대해 ΔQ·c>ΔT인지도 검사한다. 모델 학습비는 한 번짜리 연구와 반복 배포를 나누어 상각한다. JSON의 정답을 읽는 작업만 빠르게 모사해서 실용 성능을 주장하지 않는다.

## 3. 추천 대안: 미래의 판정과 경계를 예측하는 일관된 학습

**새 연구 질문:** “처음 0.20초만 관측했을 때, 이후 0.25–0.45초의 신호 상태와 힘 경계를 여러 합리적 판정 규칙에 일관되게 예측할 수 있는가?”

이것은 현재 완전정확 질의 과제의 지표를 바꾸는 것이 아니라, 별도 목표·손실·분할을 가진 **새 프로토콜**이다. 핵심은 미래 예측이며, 같은 시각의 규칙 특징을 넣어 그 규칙 라벨을 맞히는 모사가 아니다. 112,400개 stroke의 고정 prefix/future 특징이 로컬에 있으므로 대규모 다운로드 없이 시작할 수 있다. 다만 모든 설계가 동일하지 않으므로 먼저 기존 78,000개에서 배관을 검증하고, 추가 자료의 장력·고하중·반복 설치·냉온 조건을 명시적으로 매핑한다. 이들은 외부 미노출 자료가 아니다.

가능한 기술적 중심은 **판정 규칙 사이의 논리적 일관성을 보존하는 미래 확률 모델과 구조적 경계 손실**이다. 예를 들어 현재 3×3 periodicity/ratio 규칙군은 같은 신호의 두 수치를 비교하므로 임의의 9비트 라벨이 나올 수 없다. 공통 guard/fixed를 사용하는 정확히 이 규칙에서는 9개의 비독립 이진 head 대신 가능한 10개 라벨 패턴의 확률을 학습하는 작은 범주형 head를 구성할 수 있다. 이때 각 규칙 확률과 첫 K-run 분포를 유도한다. 실제 target의 guard/fixed와 버전을 검증하기 전에는 이 10패턴 구성을 적용하지 않는다.

범주형 잠재 상태, 순서 제약, CRF/구조적 예측, 미분 가능 DP 자체는 기존 기술이다. 후보 기여는 **공통 판정 기준의 불확실성을 일관되게 표현하고, 예측이 downstream 경계에 주는 영향을 직접 학습·검증하는 결합**이다. 이것도 문헌과 ablation을 통과하기 전에는 신규성 주장 후보다. [미분 가능 DP](https://proceedings.mlr.press/v80/mensch18a.html)

필수 비교는 persistence, source-fitted Markov, 규제 logistic, controls-only HGB, 마지막 prefix snapshot HGB, prefix-history HGB, 작은 TCN, 독립 9-head 모델, 공동 10-pattern 모델이다. 같은 정보·같은 split·동일 신경망 배치와 업데이트 수를 사용한다. 공동 head의 이득과 경계 손실의 이득을 따로 분리한다.

주 지표는 사전에 선택한 미래 규칙 확률의 평균 log loss다. Brier, entry/exit 부분집합, 최악 계열, 보정, 경계 rank 오차, 계산비를 보조 지표로 둔다. 실제 물리 정답·음질 점수가 아니라 **고정 관측 규칙의 미래 출력**이다. 외부 수동/물리 정답이 없으면 그 한계를 유지한다.

반박 조건은 명확하다. 이력 HGB·persistence를 못 넘으면 표현 학습 필요성 미입증이다. 공동 head의 이득이 단순한 독립 head의 사후 일관성 보정과 같으면 새로운 모델의 필요성 미입증이다. 경계 개선이 점별 확률 악화나 한 계열의 효과에만 의존하면 일반적 개선으로 쓰지 않는다. 사전 고정한 최소 효과와 계열별 손해 한계를 넘지 못하면 종료한다. 효과 기준은 train 내부 교차검증의 변동과 실제 downstream 비용으로 정하고 외부 개발 점수를 본 뒤 고르지 않는다.

시간 누출 방지가 최우선이다. 미래 힘·미래 특징·전체 길이·미래 NaN 꼬리·전체 파형에서 계산한 onset은 입력 금지다. plateau 기준점은 사전에 주어진 실험 프로토콜인지, 미래를 본 검출값인지 확인한다. 후자라면 “실시간 예측” 주장을 중단하거나 causal landmark를 별도로 검증한다. 표본 분리는 stroke보다 상위인 실제 현 표본/설치 계열로 하고, 동일 현의 냉온·반복 설치를 양쪽에 섞지 않는다. 구형 미래 observer와 최신 joint-rule observer는 자동으로 같은 라벨이 아니므로 버전·재구성 fixture를 고정한다.

## 4. 보조 대안: 주어진 비용 안에서 경계 예측 위험을 줄이는 학습 정책

정확 인증에서는 이미 남은 개선 여지가 작지만, 예산이 5·10개인 경우에는 아직 답을 모르는 열이 많을 수 있다. 별도 프로토콜에서 **예산 10개일 때의 구조화 경계 예측 손실**을 주 목표로 잡을 수 있다. 예산·손실·none 범주·오판 비용·미결 처리·규칙군 집계를 결과 전에 고정한다. 예산을 여러 개 돌린 뒤 가장 좋아 보이는 것만 고르지 않는다.

후보 방법은 공동 규칙 패턴 모델, 경계 손실을 목표로 하는 Bellman risk-to-go, 최종 exact checker를 결합한 획득 정책이다. 정확 인증이 안 된 예산에서는 불확실한 예측이라는 점을 명시한다. 근시안 entropy, uncertainty, source-fitted prior, EC²류 의사결정 구분, 작은 n의 정확 최적 정책이 필수 비교다. 능동 특징 획득과 비근시안 위험 최소화는 기존 방법이며 최근에도 연구되고 있다. [EC²](https://papers.nips.cc/paper_files/paper/2010/hash/1e6e0a04d20f50967c64dac2d639a577-Abstract.html), [BRiG-AFA, 2026](https://arxiv.org/abs/2608.02305)

이 경로는 정확성 보장을 약화해 점수만 올렸다는 비판을 받을 수 있다. 따라서 독립적으로 의미 있는 비용 제약과 오판 비용이 없으면 시작하지 않는다. full-observation oracle 대비 regret, 미결률, 실제 시간으로 평가하며, abstention으로 어려운 사례를 빼지 않는다. 고정 예산에서 단순 greedy를 이기지 못하거나 정책 계산 시간이 판독 절약보다 크면 종료한다.

## 5. Foundation model과 바이올린 적용의 조건

현재 주 자료는 첼로 현의 bridge/nut 기계 신호이며 일반 마이크 음악 오디오가 아니다. 112,400개 모두의 raw waveform이 보존된 것도 아니다. MOMENT 같은 시계열 모델의 frozen embedding이나 작은 TCN을 비교할 수 있지만, 음악 FM을 최신이라는 이유로 채택하지 않는다. raw 표현이 사전 특징을 넘을 필요가 있고, 입력 종류·샘플링·라이선스·그룹 분리가 맞을 때만 시작한다. [MOMENT](https://arxiv.org/abs/2402.03885), [MuQ](https://arxiv.org/abs/2501.01108)

바이올린을 과제의 필수 대상으로 유지하려면 공개 바이올린 자료의 실제 라벨·센서·bowing 정보가 제안 목표에 맞는지 별도로 확인해야 한다. 단순 바이올린 음원은 첼로의 활 힘·β 경계를 검증하지 못한다. 적합한 공개 자료가 없으면 “현악기 일반/바이올린에서 검증”을 쓰지 말고 **첼로 현 실험에 적용한 AI 신호 방법**으로 범위를 좁힌다. 이번 문서는 외부 데이터 존재를 새로 검증하지 않았다.

## 6. 우선순위와 정직한 신규성 등급

| 방향 | 현재 신규성 판단 | 다음 결정 |
|---|---|---|
| 정확 인증 + 학습 prior | 구성 요소는 확립됨. 현재 개선 미입증, 16개에서 10% 불가능 | 한 번의 전체 개선 여지 진단 후 종료/제한 평가 |
| 일관된 미래 규칙·경계 학습 | 가장 실질적인 AI 질문. 결합의 차별성·성능은 아직 가설 | 추천 후속. 데이터/누출 검사와 강한 HGB부터 |
| 비용 제한 위험 기반 획득 | 가까운 선행연구 많고 비용 정당화 필요 | 비용 병목과 미결 허용 목적이 확인될 때만 |
| 유명 FM 추가·LLM 연구 루프 | 자체로 과학적 신규성 없음 | 표현 기준선/연구 운영 도구로만 사용 |

문헌 검토는 관련 1차 문헌을 중심으로 한 표적 조사다. 인터넷 전체나 2026년 최신 연구를 빠짐없이 검토했다는 뜻이 아니다. 좋은 종료 결과는 “AI가 효과를 냈다”만이 아니다. 개선이 구조적으로 불가능한 문제를 정확히 중단하고, 검증 가능한 미래 예측 문제로 이동하는 판단도 이번 자동 연구 시스템의 중요한 기능이다.
