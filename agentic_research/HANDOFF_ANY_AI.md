# 공동연구 인계 프롬프트 — Claude·Codex·기타 AI 공통

**2026-11-02 최종 상태:** 공개 바이올린 원음 51명/2168녹음의 고정 12개 비교와 시험 1회 평가까지 완료·STOP이다. Markov 0.552413 대비 offset 0.664192로 손실이 20.23% 높아 개선은 미입증이다. `violin_raw_v1/RESULTS.md`, `FINAL_AUDIT.json`, `docs/WORK_QUEUE.md` 최상단을 읽는다. 자동화 `ai`는 PAUSED다. 아래 원음 준비/실행기 대기 지시는 이전 이력이다. 완료한 train/evaluate/prepare를 반복하거나 동결 파일·점수·test를 변경하지 않는다.

**2026-10-30 추가 인계:** 현재 다음 행동과 로컬 미커밋 작업은 [CLAUDE_NEXT.md](CLAUDE_NEXT.md)에 갱신했다. projection 보완 v2는 이미 완료/종료했고, 저장 MAT 대신 raw WAV에서 시간 지지가 명확한 입력을 만드는 준비 단계다. 아래의 보완 검증 대기·MAT 후속 계획을 그대로 실행하지 않는다. v3 결과와 기존 금지 사항은 유지한다.

당신은 이 저장소의 공동연구자다. 사용자는 미래 예측 AI 연구, 데이터 누수 검증, 공개 바이올린 자료 적용, 여러 AI가 이어갈 수 있는 재현 가능한 자동 루프를 요청했다. 좋은 숫자를 만들기 위해 목표나 평가 조건을 바꾸는 것은 허용하지 않았다.

먼저 저장소의 `agentic_research/START_HERE.md`, `docs/EXECUTION_STATUS.md`, `AGENTS.md`, `forecast_v3/DATA_AUDIT.md`, `forecast_v3/configs/forecast_v3.json`, `forecast_v3/COHERENT_REPAIR_REVIEW.md`, `forecast_v3/violin_data_audit/README.md`를 읽고 실제 status·프로세스·Git 상태를 확인하라. 이 파일에 적힌 진행 상황보다 봉인된 실행 결과와 최신 상태 문서가 우선한다.

## 이미 확정된 사실

- 기존 연구의 물리 법칙 주장은 많이 철회되었으며, 판정·경계의 정확 민감도 분석이 남았다. 과거 보고서를 새 AI 성과로 바꾸어 쓰지 않는다.
- v1의16열, v2의480열 정확 질의 수 과제는 각각7.77%,5.83%의 개선 상한 때문에10% 목표가 불가능하여 종료했다. source나STOP을 고쳐 같은 목적을 계속 돌리지 않는다.
- 현재 후속은 초기0.20초 특징으로 이후0.25–0.45초의 고정 관측 규칙 출력을 예측한다. 입력60차원,54,000학습/24,000개발,9개규칙/10개허용패턴이다. 원래78,000개 판정 재구성은 불일치0건이었다.
- plateau landmark가 전체 신호에서 정해져 엄격한 실시간 예측이라고 주장할 수 없다. 미래 행에서 입력 특징으로 흐르는 누수와 landmark 자체의 미래 의존성을 구분한다.
- 모든 첼로 자료는 과거 노출된 자료다. 분할과 seed를 새로 만들었다고 미사용 확인시험이 되지 않는다. 학습·전처리는 A/B에서만 하고 C/D는 회고적 개발 평가로 보고한다.
- 독립/공동 신경망은 같은 backbone·배치·업데이트·9규칙 BCE로 비교한다. HGB와 source-trained Markov가 강한 기준선이다.10패턴 표현·확률 coherence projection·Bregman 정리 자체는 기존 기술이다. 특히 Predd2009와 Forecast@ICML2026 선행을 숨기지 않는다.
- v3의 고정 비교 12개는 모두 완료되어 STOP이다. 공동 head는 보정 HGB보다 log loss가 3.335% 낮지만 독립 head보다 0.185% 높다. 구조 자체의 추가 이득은 입증되지 않았다. 원예측을 독립 재계산한 주 점수 차이는 0.0이며, 결과는 `published_results/forecast_20261030_v3/`에 있다.
- 후속 `projection_audit_v1`도 256개 예측의 정답 비열람 수치 감사를 완료했다. SLSQP 성공 표시와 달리 엄격한 FW gap 조건은 50개만 통과했고 보정 최종 채택은 28개였다. 결과를 정확 참조 solver나 새 성능 개선으로 주장하지 않는다. 별도 보완 검증은 작업 큐에 정한 한 번만 허용한다.
- 공개 바이올린 Blanco 자료는 받아checksum과시계열을 확인했다.72개참여자기록,2,117개고유음향시퀀스다. 중복·F0단위·시간표시·동작정렬 문제가 있어 우선frame-defined음향지표예측만 준비한다. 아직 바이올린 모델 성능 결과는 없다.

## 다음 행동

1. 실제 프로세스·상태부터 확인하되 완료된 v3를 재개하지 않는다. 모든 설정·시드와 실패한 실행을 보존한다. 다른 컴퓨터의 재현 실행은 `START_HERE.md`의 새 캠페인을 사용한다.
2. `published_results/forecast_20261030_v3/FORECAST_REVIEW.md`와 `docs/NEXT_METHOD_REVIEW.md`의 반박을 읽는다. 현재 근사 보정의 fallback을 정확 KL projection의 한계라고 쓰지 않는다. 결과 라벨과 무관하게 정한 작은 예측 집합에서 참조 solver의 수렴·제약·비용을 확인하는 작업부터 별도로 고정한다.
3. 공동 head가 강한 HGB를 넘었다는 사실과 독립 head를 넘지 못했다는 사실을 함께 보고한다. 논리 정합성과 예측 향상을 혼동하지 않는다. 임의 임계값 예측을 위한 조건부 CDF·혼합모형도 기존 기술이므로 단순 도입을 신규성으로 주장하지 않는다.
4. 바이올린 후속은 참여자 단위 분할, 내용 해시 중복 제거, prefix-only정규화, 미래창 불겹침을 먼저 검증한다. 미래 목표·문턱은 train에서만 정하고 test는 고정후 한 번 평가한다. timestamp를 지어내거나 동작 신호를 길이에 맞춰 억지 정렬하지 않는다.
5. 방법을 바꿀 필요가 생기면 직접 선행·차이·필수 대조군·반박 조건을 써서 독립 검토하고, 별도 코드/계약을 테스트·동결한 뒤 실행한다. 현재 버전의 manifest를 삭제·재동결해 우회하지 않는다.

## 자동화와 소통

`run_forecast.sh tick --proposer-backend claude --reviewer-backend codex`처럼 제공자를 바꿀 수 있다. 다른 AI는 `manual` JSON 모드로 연결한다. 응답의 request_sha와 후보 semantic_sha를 그대로 확인하라. LLM의 승인이 고정 평가기의 검사를 우회할 수는 없다.

한 차례에 가설·실험·결과·반박·다음 행동을 기록하고 `docs/EXECUTION_STATUS.md`를 갱신한다. 새 무관한 연구를 계속 추가해 종료를 미루지 않는다. 성공을 보장하지 않는다. 학습 로그·계정 정보·개인 설문·대용량 원자료는 Git에 올리지 않는다. 이미 공개 허가와 출처를 확인한 준비 데이터는 `benchmarks/forecast_v3/`만 사용한다.

사용자에게는 한국어로, 무엇을 실제 실행했는지와 무엇이 아직 계획인지를 분명히 말한다. 논문 수준의 novelty가 확보되지 않았다면 그대로 말한다. 원자료의 숨은 문제와 강한 반박 결과도 성과이며, 그것을 감추고 높은 성능을 주장하지 않는다.
