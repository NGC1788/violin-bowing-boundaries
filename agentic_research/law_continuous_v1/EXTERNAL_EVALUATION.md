# 미사용 실제 자료 점검

이번 점검에서 기존 규약과 호환되면서 미노출을 확인할 수 있는 실제 코호트를 확보하지 못했다. 로컬의 A2 원자료는 기존 분석 자료다. 같은 공개 컬렉션의 보관된 특징 파일과 기록을 대조했다. Cold/warm은 과거 동결 시험에서 이미 채점했고, Part 5의 D_T2와 B_T2 두 번째 표본 및 고하중 계열도 과거 확인 또는 사후 분석에 사용됐다. 이번 C/D 결과는 이들과 별개로 반복 노출된 개발 평가다. [기존 확인 기록](../../research/2026-10-19_protocol_audit/final/최종보고서.md) · [컬렉션 Part 3](https://zenodo.org/records/17782552) · [Part 5](https://zenodo.org/records/17782538)

별도 공개 후보도 확인했다. Lampis의 트랜지언트 자료는 힘·가속도에서 발음 시작을 보는 실험이다. Mores의 광학 자료는 일정 접촉 위치에서 세 힘 수준의 규칙적 운동을 기록했고, 전자기 자료는 전자기 변위 채널을 제공한다. 현재 목표에 필요한 일정 속도·복수 접촉 위치에서의 계측 힘 순서와 브리지 파형을 그대로 제공하는지 확인되지 않아 외부 평가로 사용하지 않았다. [발음 시작 실험 자료](https://zenodo.org/records/10946413) · [광학 자료](https://zenodo.org/records/1302895) · [전자기 자료](https://zenodo.org/records/1257872)

외부 평가는 기존 적합에 쓰이지 않은 측정 세션을 단위로 고정해야 한다. 필요 입력은 여러 β 위치의 일정 속도 실험, 각 위치의 힘 계측과 반복 긋기 파형, 기존 판정 특징을 재현할 수 있는 브리지 신호와 측정 창이다. 이전 대상 열 선정은 기본 판정에서 유한 경계를 가진 열을 사용하므로, 새 세션의 목록을 만들 때 드는 파형 조회를 비용에 포함하거나 결과를 이미 제공된 목록에 조건부로 표시해야 한다. 양립·불양립의 실제 구성은 사전에 고정한 전체 세션과 허용 거리를 일괄 채점해 보고하고, 확인 후 한쪽 사례만 골라내지 않는다.
