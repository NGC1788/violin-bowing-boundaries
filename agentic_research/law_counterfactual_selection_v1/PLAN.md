# Counterfactual interval lookahead

New bounded retrospective experiment. Use the original 12 C/D folders, existing eligibility roster, nine rules and unchanged stop. Primary tolerance 0.2. Report 0.4 as an additional scope check with both outcomes. Check terminal decisions against the saved full decisions. Run each declared policy once. Limit the whole process to 600 seconds. No threshold, seed, weight or shortlist tuning.

First reproduce the saved HGB trajectory and its uniform comparator at 0.2 using one refit of the original fixed A/B prior, since the previous experiment retained counts rather than query traces. Require identical counts. Record first divergent query ranks, queried rank distribution, and the number of live rules after each policy spends the baseline budget. Report every folder, not just the largest regression.

The proposed policy ranks a shortlist of unqueried waveforms by the effect of each feasible nine-rule response on the actual outer intercept intersection. Shortlist: the six largest existing priority scores, the earliest unobserved rank, and one available bit per binding endpoint and rule. The latter tries the required positive pair and predecessor of an endpoint candidate, in rank order. Deduplicate without truncating. For each response, replace just that column's intervals and combine them with cached endpoints of all other columns. Rank by expected number of eliminated live rules, then expected reduction in summed nonnegative live interval width, then the existing priority and its tie break. Use A/B response-pattern frequencies with one pseudocount per feasible pattern. Uniform pattern probabilities are the matched ablation. Rules share a waveform, so each hypothetical response is a joint vector, not independent Bernoulli draws.

Primary success requires exact decisions and fewer total queries at 0.2 than the existing policy. Also report per-folder wins/ties/losses, worst regression, both outcomes at 0.4, and CPU time. The exposed C/D folders remain a development cohort, including where earlier policy performance was known. No external generalization claim.
