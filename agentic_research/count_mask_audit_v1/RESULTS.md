# 합성 연산기 검증: 수학적 계산은 일치, 현재 beam 실용 기준은 실패

2026-11-02. **AI·정보 연구의 연산기 검증**이다. 실제 바이올린 자료나 모델 성능을 평가하지 않았다. 새 학습0건이다.

판정은 **`FAILED_PREDEFINED_GATE_STOP`**이다. 소스 검토·합성 시험8개 후 계약을 동결하고 공유 수치 예산의 마지막 시도를 한 번 실행했다. 10개 기준 중9개가 통과했지만, 집중 분포 사례의64-state beam이 정한 누락 유효 질량0.002 이하를 충족하지 못했다. 기준을 완화하거나256-state 결과를 대신 주 결과로 선택하지 않는다. 이전 결과와 이번 실패는 보존한다.

## 구현한 AI 연산

미래의 관측 마스크를 외우는 사전 대신, prefix로 예측할 수 있는 이진 Markov 마스크 법칙과 두 잠재 regime의 경로 분포를 정의했다. 구간별 관측 개수를 유지하는 동적계획으로 마스크를 주변화하고, 비중심 chi-square CDF로 미래 표본 변동량의 공동 사건을 계산한다. 실제 미래 마스크를 추론 입력으로 쓰지 않는다.

조건부 iid Gaussian·구간별 평균이라는 제한 아래에서, 같은 구간별 개수는 같은 조건부 통계 법칙을 준다. 이 제한 때문에46프레임의 모든 이진 마스크를 직접 열거할 필요가 없다. 작은 경우의 전수 열거와 큰 경우의 별도 NumPy 사전 구현을 대조했다. Count DP와 chi-square 법칙 자체는 기존 방법이다.

| 검사 | 결과 |
|---|---:|
| 작은 경우의 count 확률 최대 차이 | 1.11×10⁻¹⁶ |
| 전수 열거 CDF/확률 경계 최대 차이·위반 | 2.22×10⁻¹⁶ |
| 큰 경우의 별도 DP와 CDF/경계 차이·위반 | 4.44×10⁻¹⁶ |
| local mask-logit 미분 경계 위반 | 0 |
| 고정 선택 상태에서 유한차분과 미분 최대 차이 | 8.17×10⁻¹³ |
| 같은 경로 법칙의 평균 근사 경계 위반 | 0 |

미분은 마스크 logit에 대한 query partial이다. Gaussian-head 전체나 공유 신경망의 gradient를 검증한 결과가 아니다. 실제 수치 연산은 float64이며 검증된 구간 연산에 의한 보편적 인증은 아니다.

오차 경계는 실패를 정확하게 드러냈다. 작은 beam으로 늘 충분하다는 주장은 성립하지 않는다. 본 구현은 dense grid에 pruning mask를 곱하는 프로토타입이다. 희소 상태만 계산하는 O(TL) 구현의 효율을 입증한 것이 아니다.

고정46프레임·2regime·2block·1example에서 CDF 값을 매번 다시 계산하고 마스크 logit으로 역전파한 중앙값은 다음과 같다. 모든5회씩의 원 시간은 [RESULTS.json](RESULTS.json)에 저장했다.

- 정확 dense count 계산: **13.945ms**.
- 64-state beam: **14.748ms**, dense의1.05757배.

따라서 이번 구현의 beam 가속 주장은 기각한다. 이 시간은 작은 fixture의 마스크 미분까지이며 전체 신경망 학습 속도가 아니다. 실질적 다음 후보는 더 단순한 **정확 count decoder를 쓰는 학습 모델**이다. 이번 실패를 지우고 그 모델이 이미 성공했다고 표현하지 않는다.

## 가정의 반박 시험

상관 Gaussian 혁신의 두 프레임 예에서는 선택된 프레임 수가 같아도 프레임 간 거리에 따라 표본분산 법칙이 달랐다. 같은 std 문턱에서 CDF 차이는 **0.198796**이었다. 이는 의도한 음성 대조 결과로, count만으로 일반적인 상관 잡음까지 처리할 수 없음을 보여 준다. 실제50ms 기술자 창은10ms 간격으로 겹치므로 조건부 iid 가정은 특히 주의해야 한다. Raw 기술자 상관이 그대로 혁신 상관이라는 뜻도 아니다.
