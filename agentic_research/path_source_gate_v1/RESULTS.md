# 바이올린 미래 경로 준비 완료, 현재 유한 마스크 사전은 관문 실패

2026-11-02. 자료 준비는 성공했고, 현재 사전 기반 마스크 모형은 사전에 정한 운영 기준을 통과하지 못했다. 이번 단위에서 모델을 학습하거나 예측 성능을 평가하지 않았다.

## 확인한 것

원래 학습 자료 **34명·1,442개 녹음**의 미래 1.25–1.75초에서 각각 **46개 프레임**을 추출했다. 경로로 다시 계산한 음높이·음량 표준편차는 기존 학습 정답과 **최대 절대 차이 0.0**이었고, 유성 판정이 충분한지를 나타내는 guard도 완전히 일치했다. 유효 1,427개와 무효 15개를 모두 보존했다.

정답과 무관한 ID 해시로 고른 실제 녹음 8개에서 미래 전체를 NaN으로 바꿔도 prefix의 60개 요약 및 96×4 프레임 입력이 그대로였다. 같은 8개에서 미래 구간 밖을 NaN으로 바꿔도 미래 기술자와 정답이 그대로였다. 이는 특징 추출기의 시간 지지를 확인한 검사다. 원본 파일의 PCM 동일성 검사는 별도이며 파일을 변조하면 그 동일성 검사가 실패하는 것이 정상이다.

Prefix 입력, 행 정렬·참여자 메타데이터, 미래 경로·마스크·정답을 서로 다른 비공개 파일로 저장했다. 개발·시험 정답 파일은 열거나 해시하지 않았다. 기존 동결 코드와 입력은 변경하지 않았다. 자료 준비 **1회, 9.154771초**, 새 학습·다운로드 **0건**이다.

## 유한 마스크 사전의 지원 범위

전체 1,442개 중 1,360개는 미래 프레임 46개가 모두 유성이다. 그러나 전체 마스크는 78종이며, 드문 패턴을 단순 사전으로 처리할 때 참여자 간 지원 범위가 다르다. 전체 사전은 기술 통계로만 계산했으며 예측용 사전으로 사용하지 않았다.

각 분할에서 **제외한 참여자의 미래 마스크를 보지 않고**, 내부 학습 자료만으로 사전을 만들었다. 미지 비율은 녹음 수 기준이며 성능 지표가 아니다.
