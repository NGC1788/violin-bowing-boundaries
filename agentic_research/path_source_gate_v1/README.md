# 바이올린 미래 경로 자료 준비 감사

이 단위는 새로운 모델의 성능 시험이 아니다. 원래 학습 자료 34명·1,442개 녹음에서 미래 경로를 별도 정답 파일로 준비하고, 앞서 수치 검증한 제한된 모형을 적용할 자료 기반이 있는지 확인한다. 과거에 노출된 학습 자료 내부의 탐색이라는 한계가 있다.

입력은 처음 1초의 기존 60개 요약과 96×4 프레임 기술자다. 미래 1.25–1.75초의 46개 프레임에서 음높이(cents), 음량(dBFS), 주기성, 유성 판정을 추출한다. 미래 경로·유성 마스크·guard는 정답 파일에만 저장한다. Prefix 입력 파일에는 미래 정답과 기록 식별자를 넣지 않으며, 행 순서·참여자·분할은 별도의 비공개 메타데이터로 보존한다.

이미 봉인된 학습 정답의 음높이·음량 표준편차를 경로에서 다시 계산한다. 표본 표준편차의 자유도 보정은 `ddof=1`, 음높이는 유성 프레임이 최소 23/46개인 경우에만 유효하다. 무효 행도 삭제하지 않는다. 정답 재구성 실패는 준비 실패이며, 허용 오차를 바꿔 재실행하지 않는다.

세 참여자 분할마다 내부 학습 부분의 마스크만으로 사전을 만든다. 제외한 참여자들의 실제 미래 마스크를 사전에 추가하지 않고, 사전에서 보지 못한 패턴의 비율을 전체 행과 유효 행에서 각각 보고한다. 내부 학습 마스크가 64종 이하이고 제외한 유효 행의 미지 패턴이 5% 이하인지를 사전에 정한 운영 기준으로 확인한다. 이 기준은 모집단의 보장이나 성능 개선 기준이 아니다. 전체 자료의 고유 패턴 수는 기술 통계일 뿐 출력 사전으로 사용하지 않는다.

원본 코드와 자료의 이전 봉인을 확인한 뒤, 합성 누수 시험·별도 코드 검토·새 계약 동결을 거쳐 준비를 한 번 실행한다. 실제 녹음 8개는 정답을 보지 않는 ID 해시 순서로 고른다. 미래를 NaN으로 바꿔도 기존 prefix 입력이 그대로인지 확인하고, 미래 구간 밖을 NaN으로 바꿔도 미래 정답이 그대로인지 역방향 시간 지지도 확인한다.

예산은 준비 600초, 학습 0건, 다운로드 0건이다. 비공개 시작 마커가 실패 후에도 남으며 중복 실행을 거부한다. 원음·경로·행별 마스크·개인 정보는 공개하지 않고 코드, 집계, 파일 해시만 공유한다. 계산한 원시 경로 상관을 Gaussian 혁신의 상관이라고 해석하지 않는다.

개발 중 합성 시험 명령은 다음과 같다. 실제 준비가 끝난 뒤에는 `run`이나 `freeze`를 반복하지 않는다.

```bash
.venv-mac/bin/python -m pytest --import-mode=importlib -q agentic_research/path_source_gate_v1/test_gate.py
```

자료 준비 승인은 새 학습의 승인이 아니다. 후속 모형은 별도 가설, 공정한 대조, 미래 누수 검사, 검토와 동결을 거쳐야 한다.
