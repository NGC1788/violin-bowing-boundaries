# 사후 원인 분석 경계

- `../violin_raw_v1`의 동결 소스·입력·가중치·예측·점수는 읽기 전용이다. 기존 캠페인의 train/evaluate/freeze를 호출하거나 새 모델을 적합하지 않는다.
- 실제 숫자 진단에 허용된 정답은 기존 train/dev만이다. `test_labels.npz`를 열지 않는다. 기존 test 집계는 이미 노출된 참고 자료이며 새 확인시험이 아니다.
- 가중치는 원래 예측 봉인에 포함되지 않았으므로, 저장된 dev 예측 재현으로 행동 일치를 먼저 검사하고 사후 hash를 별도로 기록한다. train forward pass는 가중치를 바꾸지 않는다.
- 모든 원인 진단은 사후 분석이다. 연관성, 구현 증거, 반증된 가설, 아직 식별되지 않은 원인을 구분한다. 진단을 실제 성능 개선이나 인과 증명으로 부르지 않는다.
- 후속 방법은 직접 선행과 실제 차이, 필요한 대조군, 실패 조건, 독립 확인자료의 가용성을 먼저 정한다. 기존 test를 새 미사용 시험으로 재포장하지 않는다.
- 원자료·개인 설문·행별 정답/예측·원시 CLI 로그를 공개하지 않는다. 공개 결과는 코드·집계·출처·해시로 제한한다.
