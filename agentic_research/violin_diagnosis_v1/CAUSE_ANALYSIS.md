# 작은 신경망이 기준선보다 나빴던 이유: 사후 원인 분석

2026-11-02. **현재 근거는 새 참여자 일반화 실패와 확신한 오답의 손실 집중을 지지한다. 특정 입력이나 학습 단계가 원인이라는 인과 증명은 없다.** 여기서 신경망은 고정된 60→32→9/10 MLP 세 종류다. 신경망 전체나 최신 tabular 모델의 한계를 보인 실험이 아니다.

기존 [시험 결과](../violin_raw_v1/RESULTS.md)는 보존했다. 새 학습 0건, test 정답 재열람·재평가 0건이다. 저장된 모델을 복원해 train/dev에만 forward pass를 했다. 원래 봉인한 9개 신경망의 dev 예측과 복원 예측의 최대 차이는 **0**이었다. 원래 가중치는 예측 봉인에 포함되지 않았으므로, 이 행동 일치와 사후 가중치 hash를 소급 봉인이라고 부르지는 않는다.

## 1. 최적화 불능보다 일반화 격차가 명확하다

손실은 참여자마다 녹음과 9개 규칙 BCE를 평균하고 참여자를 동일 비중으로 평균한다. 신경망은 세 seed의 손실 평균이다. 작은 값이 좋다.

| 모델 | train log loss | dev log loss |
|---|---:|---:|
| Markov | 0.533097 | 0.536024 |
| 독립 MLP | 0.446968 | 0.667854 |
| 공동 MLP | 0.427981 | 0.689983 |
| prior offset MLP | **0.422824** | **0.710557** |

학습 참여자 34명의 1,442개 녹음에서는 더 잘 맞지만 새 참여자 8명의 337개 녹음에서는 나빠진다. 1,442개 녹음이 1,442명의 독립 사람을 뜻하지 않는다. 이는 참여자 간 일반화 격차의 증거다. 최적 epoch, 개인 식별 정보의 암기, 정규화 부족 중 무엇이 원인인지는 endpoint만으로 구분할 수 없다. 학습 곡선이나 해당 개입 실험은 없다. 부호·패턴 순서·주변화·가중치 계산에서 이 실패를 설명할 구현 오류는 발견하지 못했다.

## 2. 드문 확신 오류가 log loss를 크게 만든다

여기서 확신 오류는 실제 1에 확률 <0.05 또는 실제 0에 확률 >0.95를 준 경우다. 비율은 사람·규칙 macro이며 단순 정수 건수 비율이 아니다.

| 모델 | dev 확신 오류 비율 | dev 전체 손실 중 그 오류의 몫 |
|---|---:|---:|
| Markov | 0.300% | 1.746% |
| 독립 MLP | 3.179% | 36.845% |
| 공동 MLP | 3.418% | 38.021% |
| offset MLP | **4.083%** | **40.956%** |

신경망 손실 몫은 `seed 평균 오류손실 기여 / seed 평균 전체손실`이다. 원시 진단의 `wrong_95_loss_share`를 seed 평균한 값과 조금 다르다(offset 40.944%). 둘을 혼동하지 않는다. HGB는 dev Brier가 Markov보다 좋았지만 log loss는 나빴다. 주 점수가 무엇인지에 따라 결론이 달라지므로 Brier 개선으로 주 실패를 대체할 수 없다.

offset에서 한 참여자가 전체 Markov 대비 초과손실의 **64.62%**를 차지했다. 독립·공동 MLP에서는 각각 85.53%, 81.80%다. 이 사람을 제외하지 않았고 모든 원점수에 포함했다. 잘못 그은 연주인지, pitch 관측기 오류인지, 조건부 분포 변화인지까지는 확인되지 않았다. 낮은 확률을 주고 틀린 것이 손실을 키운 직접적 산술 경로라는 의미다.

## 3. prior를 넣어도 보정의 크기는 제한되지 않았다

offset은 다음 모형이다.

\[
q_\theta(z\mid x,s)
=\operatorname{softmax}_z\{\log\pi_s(z)+f_\theta(x)_z\}.
\]

행별 상수를 빼 softmax의 비식별성을 제거한 residual norm은 train **4.656**, dev **8.299**였다. 분포 엔트로피는 1.552 대 1.346으로 dev에서 작았다. 음의 centered log-prior에 대한 residual cosine은 −0.072 대 −0.177이었다.

따라서 prior를 통째로 상쇄했다는 설명은 지지되지 않는다. 평균적으로 prior와 같은 쪽으로 일부 정렬되며, dev 보정이 더 크고 더 확신적이라는 설명이 맞다. 모든 행이 prior를 증폭했다거나, 이 norm 자체가 실패를 일으켰다는 뜻은 아니다. 이 수치는 학습 시간에 따른 증가가 아닌 서로 다른 자료의 최종 모델 비교다. 실제로 가장 큰 입력 이탈·보정 norm을 보인 사람도 Markov보다 나았으므로 norm만으로 복귀시키는 장치는 근거가 약하다.

## 4. 입력 이탈과 음량 민감도만으로는 실패를 가려내지 못했다

표준화 전처리에서 |z|>3인 특징의 사람 평균 비율은 train 1.772%, dev 5.113%였다. 하지만 가장 크게 이탈한 참여자는 offset이 Markov보다 나았다. 이탈이 있다는 사실과 그 보정이 해롭다는 사실은 다르다.

고정 gain 0.5와 2.0만 검사했다. PCM·메타데이터 hash를 검증하고, clipping·RMS floor·voicing 문턱을 넘지 않는 조건을 확인했다. dev 337개는 두 변환 모두 이 조건을 만족했다. 각 gain마다 source-ID hash 순서의 8개 녹음에서 원음 특징·목표를 재계산했다. 원래 특징·prefix 상태·목표·판정이 준비 자료와 일치했고, gain에 따른 9개 음량 수준 특징 이동의 최대 오차는 **4.27×10⁻¹³** 미만, 16개 검사 모두 9규칙 판정이 유지됐다. 이는 표본 수치 검증이며 전체 자료의 연속 관측기 재계산은 아니다.

offset의 예측 확률 평균 절대 변화는 gain 0.5에서 **0.0706**, 2.0에서 **0.0535**였다. 그러나 사람별 민감도와 Markov 대비 초과손실의 Spearman 상관은 **+0.286 / −0.167**로 방향이 일치하지 않았다. n=8의 서술적 상관이며 통계적 유의성이나 인과관계를 주장하지 않는다. 이번 dev에서는 모두 admission을 통과해 두 상관의 행 집합은 같았다.

**판정:** 음량 의존성은 존재한다. 이것만으로 기존 실패의 원인이나 성능이 좋은 gate가 확인되지는 않았다. 단순 OOD 거리·음량 민감도 gate를 다음 핵심 방법으로 밀 근거는 부족하다. 모든 가능한 gate의 실패를 증명한 것은 아니다.

Admission은 미래 창에서도 변환의 목표 보존을 확인한다. 이것을 배포 시 gate나 예측 입력으로 쓰면 미래 누수다. 이번에는 진단 변환의 검증에만 사용했고 바뀐 확률로 대체 성능을 계산하지 않았다.

## 5. 반박 결과와 남은 불확실성

| 가설 | 현재 판정 | 아직 모르는 점 |
|---|---|---|
| 모델이 train에서도 못 배웠다 | 이 결과와 맞지 않음 | 다른 최적화 설정의 효과 |
| 새 참여자 일반화가 실패했다 | train/dev 격차로 지지 | 정확한 인과 원인 |
| 확신 오류가 주 손실을 키웠다 | 직접 산술 분해로 확인 | 어떤 학습 개입이 고치는가 |
| prior를 넣으면 안전하다 | 반례가 있음 | 유용한 제한의 크기·조건 |
| 큰 residual은 모두 해롭다 | 반례가 있음 | 해로운 보정과 유용한 보정의 구분 |
| 음량 민감도만 줄이면 해결된다 | 채택 근거 부족 | 불변성 정규화의 실제 개선 여부 |

진단 중 별도 AI 검토가 clipping 경계 미분과 raw 대조 검사의 보완점을 발견했다. 수정 뒤 9개 합성 시험이 통과했다. 실제 확률 중 경계와 정확히 같은 값은 0건이라 기존 진단 수치 변화는 0이었다. 초기 결과는 private snapshot으로 보존하고 [수정 이력](DIAGNOSTIC_REVISION.json)에 hash를 남겼다. 별도 AI 검토는 인간 심사나 독립 경험적 확증이 아니다.

## 6. 다음 연구의 의미
