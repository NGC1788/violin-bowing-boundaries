- 미래 정답과 prefix의 시간·단위·행 정렬 문제를 구분하고, 사람 단위 분할과 innertrain-only 문턱/전처리를 검사하는 실행 체계를 구현했다. 함수 수준의 데이터 분리이며 OS 보안 격리는 아니다.
- 같은 감독·초기값·배치 순서·계산 제약의 대조를 만들고, 모든 출력 봉인 뒤 채점하는 예산 제한 실행기를 구현했다. 마지막12개 결과는 독립 scalar 계산과 최대3.33e-16 차이로 재현됐다.
- 신호 법칙/계산의 정확성, 출력 일관성, 보조 단계의 예측 보존, 전체 예측 성능을 구분해 검증했다. 앞의 성질이 맞아도 마지막 성능이 좋아진다는 결론은 성립하지 않았다.
- 불리한 fold/최악 사람/실패·clip 설계 결함까지 보존했다. 사람·행별 자료와 가중치는 private로 두고 code/docs/aggregate/hash만 공유한다.

이것들은 AI·정보 연구 수행의 근거다. 그러나 ‘새롭고 효과적인 AI 학습 방법을 확보했다’, ‘독립 바이올린 예측 성능을 높였다’, ‘최초 방법론이다’라는 결론의 근거는 아니다. Coherence/CDF/count/투영/보조 감독/재매개화 자체는 기존 원리다. 단순 조합이나 음향 적용만으로 높은 novelty를 주장하지 않는다.

무작위 방향이 null 방향보다 좋았던 인과 원인, fine label 자체의 필요성, 다른 optimizer나 더 큰 자료에서의 효과는 이 네 arm으로 식별되지 않는다. 하나의 추가 seed나 learning rate 조정으로 현재 실패를 지우지 않는다. 더 넓은 AI 방법의 효과를 부정하는 정리도 아니다.
