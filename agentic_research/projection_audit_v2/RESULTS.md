# 마지막 보정 solver 감사 결과

**결론:** 단 한 번의 사전 고정 검증을 완료했다. 전체 256개 중 239개는 정한 수치 오차 기준을 통과했고, 11개는 clipping 범위 밖의 이미 coherent인 예측을 그대로 돌려준 경우다. 나머지 **6개에서는 실제 최적화가 실패했다.** 모든 반환값은 가능한 10개 target의 clipped 점수를 악화시키지 않았지만, 모든 입력에서 수렴하는 reference solver를 얻었다고 주장할 수 없다. 이 보정 연구는 여기서 종료한다.

## 실행과 검증

- 기존 v1과 같은 64개 ID, 같은 네 모델 입력: 총 256개 확률 벡터.
- 실제 정답 target, row log loss, Brier score 등은 읽지 않았다.
- 실제 실행 전 합성 테스트 **20개 통과**, 독립 사전 검토의 identity-gap 지적을 수정한 뒤 동결.
- Manifest SHA-256: `cbf2113d40b9261136e299efd987cea7c71111d4f58454db0f47581d37e19b85`.
- 실제 audit 실행 **1회**, 약 **2.11초**. 시작 전·완료 후 동결 파일 hash 검증 통과, 결과 seal 검증 통과.
- 코드·프로토콜·결과는 변경하지 않는다. 같은 감사를 재실행하거나 제3 보정 solver로 확장하지 않는다.

## 수치 결과

| 입력 | 검사 수 | FW gap 통과 | gap을 부여하지 않은 clipping 밖 identity | 실제 gap 실패 | gap·점수 검사 모두 통과 | coherent 반환 |
|---|---:|---:|---:|---:|---:|---:|
| HGB seed 0 | 64 | 64 | 0 | 0 | 64 | 64 |
| 독립 MLP seed 0 | 64 | 58 | 3 | 3 | 55 | 58 |
| 독립 MLP seed 1 | 64 | 61 | 1 | 2 | 53 | 56 |
| 독립 MLP seed 2 | 64 | 56 | 7 | 1 | 52 | 59 |
| 합계 | **256** | **239** | **11** | **6** | **224** | **237** |

모든 후보 256개는 수치적 coherence 검사를 통과했다. gap 기준은 기존과 동일하게 `0 ≤ FW gap ≤ 1e-8`이다. 이를 통과한 행의 최대 gap은 `8.63e-12`였다. coherent identity 23개는 원래 q를 bitwise 그대로 반환했다. 이 중 clipping 범위 안의 12개는 실제 `w @ bank`에서 gap을 계산했고, 나머지 11개에는 부적절한 내부 미분값이나 가짜 0 gap을 부여하지 않았다. identity 재구성 오차는 최대 `1.74e-18`이었다.

## 남은 실패를 숨기지 않는다

실제 gap 실패 6개는 모두 line-search 실패로 끝났으며, gap이 **0.442–0.768**이었다. 이는 반올림 수준의 오차가 아니다. 이 행들의 새 후보는 기존 64회 후보보다 목적함수가 크게 나쁜 경우도 있었으며, 최대 약 `0.68311` 더 나빴다. 이 후보를 개선된 최적해로 사용해서는 안 된다. 종료 시점의 feasibility 오차 자체는 작았으므로, simplex 제약을 지켰다는 사실이 최적화 성공을 의미하지 않음을 다시 보여 준다.

전체 후보 중 가능한 target 점수를 악화시킨 경우는 21개다. 그중 15개는 gap 기준을 통과했어도 엄격한 점수 검사에 걸렸으며, 이 15개의 최대 양의 차이는 `1.69e-8`이었다. 점수 clipping과 유한 정밀도하에서 gap 검사와 실제 점수 검사는 서로 대체할 수 없다. 점수 악화 허용오차는 기존과 같이 **0**으로 유지했다.

검사에 실패하면 원래 q로 돌아갔고, identity는 q를 그대로 유지했다. 그 결과 반환값의 가능한 모든 target에 대한 최대 점수 악화는 네 모델 모두 **0**이다. 다만 **19개 반환값은 여전히 incoherent**하므로, 항상 coherent하면서 비악화인 구현을 완성했다는 주장도 하지 않는다.

## 연구 해석

v1의 gap 통과 50개보다 수치적 적용 범위는 넓어졌다. 그러나 이 수치는 예측 정확도나 논문 기여의 증가율이 아니다. 고정된 일부 입력에서 후보 목적함수가 더 낮아졌다는 사실도 실제 미래 target 예측이 좋아졌음을 뜻하지 않는다.

기존 v3의 모델 순위, joint 구조 가설의 판정, 관측 라벨 기반 성능 결과는 바뀌지 않는다. 이 과정에서 얻은 것은 고전적인 projection baseline의 수치적 한계와 실패를 기록하는 보충 감사다. 신규 AI 방법론이라고 주장하지 않는다.

**다음 단계는 바이올린 미래 예측이다.** 이미 동결된 v3 결과와 실패 기록을 보존하고, 바이올린 자료 및 실제 미래 예측 문제의 검증으로 돌아간다. 추가 projection 최적화는 이번 연구 진행에서 종료한다.
