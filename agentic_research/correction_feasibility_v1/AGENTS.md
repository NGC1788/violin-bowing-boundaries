# 조건부 보정 가능성 감사

- 이전 캠페인과 `violin_diagnosis_v1`은 읽기 전용이다. 기존 결과·규약을 덮어쓰지 않는다.
- 원래 train/dev만 허용한다. test_labels.npz는 hash 계산을 포함해 열지 않는다. 원음·개인 설문은 필요 없다.
- 새 신경망 학습·새 seed·모델 메뉴·데이터셋 탐색을 하지 않는다. PLAN.json의 고정 보정 진단만 한다.
- 보정계수 최적화는 fitting이다. 새 base-model 학습0과 혼동하지 않는다. dev oracle과 leave-one-dev-person-out 보정은 사후 탐색이며 독립 확증이 아니다.
- 겹치는 보정 학습 집합의 손실들을 iid calibration으로 취급하지 않는다. Betting의 조건부 평균 가정도 자동 충족되지 않는다.
- 새 방법·유한표본 보장·성능 개선을 주장하려면 직접 선행과 실질 차이, 유효한 자료 분리·의존 논증이 있어야 한다. 없으면 종료한다.
- 공개는 코드·집계·출처·hash만이다. 개인별/행별 자료·예측·보정 결과는 local/에만 보관한다.
