# 연구 루프 작업 규칙

사용자의 목표는 AI 방법론과 검증된 성능이다. 성공한 숫자를 만들거나 연구가 끝나지 않도록 확장하는 것이 목표가 아니다.

- 먼저 `README.md`, `docs/RESEARCH_PLAN.md`, 해당 캠페인의 protocol/status/results를 읽는다. 과거 물리 연구와 새 계산 연구를 혼동하지 않는다.
- frozen 캠페인의 `control.py`, `cli.py`, `worker.py`, `planner.py`, `harness/`, `tests/`, `prompts/`, 계약과 입력은 변경하지 않는다. 파일이 바뀌면 무결성 검사가 멈춰야 한다. 잠금 파일을 다시 써서 우회하지 않는다.
- 방법 변경이 필요하면 먼저 변경 이유·반박 실험·영향을 문서화하고, 기존 작업을 정지한 뒤 새로운 버전·캠페인으로 시작한다. 기존 결과를 지우거나 새 버전 결과와 합치지 않는다.
- 미질의 라벨·periodicity·ratio·guard·fixed, 개발 라벨을 prior 학습이나 질의 선택에 사용하지 않는다. 정책은 공개 좌표와 질의 응답만 받는다.
- 숫자는 봉인된 evaluator 결과에서만 가져온다. 실패·timeout·미결·최악 그룹을 포함한다. 결과에 맞춰 목표·분모·평가 열을 바꾸지 않는다.
- 16열은 동작 파일럿이다. 새 seed와 새 분할은 기존 자료의 역사적 노출을 없애지 못한다. 독립 확증이 없다면 그대로 쓴다.
- 같은 사용자 해시는 실수 탐지이며 보안 sandbox가 아니다. 임의 후보 Python 실행, 권한 우회, 다른 연구 파이프라인 재시작, 원자료 삭제를 하지 않는다. 사용자는 이후 코드·문서·허가된 준비자료를 `research/agentic-forecast-20261030` 브랜치에 공유하도록 요청했다. 그 범위에서만 GitHub를 갱신하며 원자료·계정정보·원시CLI로그 공개나 main병합은 하지 않는다.
- `STOP`, 해당 캠페인의 계산 예산, 최대 실패 수와 종료 날짜를 따른다. v1·v2는 종료되었다. `forecast_20261030_v3`도12개고정실험을 완료하고 종료되었다. 이후 변경은 기존결과를 보존하고 별도버전·규약으로 한다. 무개선이나 제안 소진은 정상 종료다.
- 2026-11-02 `violin_raw_v1`의고정12개학습과시험평가도완료·STOP이다. 제안offset이Markov보다20.23%높은log loss여서개선screen실패했다. 데이터/실행manifest에포함된파일은그대로보존하고같은캠페인을재실행·재동결하거나추가모델/seed/문턱을탐색하지않는다. 최신근거는 `violin_raw_v1/RESULTS.md`, `RESULTS.json`, `FINAL_AUDIT.json`이다.
