# 이식 시연: AI 강건성 감사 (2026-11-05)

## 질문
같은 인증서(바이올린 연주 가능 법칙 판정, `core.py` 그대로)를 AI 보안 문제에 붙이면, 바이올린에서 진화한 질의 정책이 **고치지 않고도** 통하는가?

## 문제 (build.py, 정책을 돌리기 전에 설계 고정)
- **모델:** 공개 MNIST로 직접 학습한 작은 CNN이다. 시험 정확도 98.36%, 가중치 sha256은 `cases/manifest.json`에 있다.
- **사례 하나:** 같은 숫자로 맞게 분류된 시험 이미지 24장 묶음과 ε의 조합이다.
- **질문:** "9개 실패 기준 중 하나라도, 모든 이미지의 가우스 잡음 파괴점이 국소 선형 강건성 법칙 σ* = C·margin/‖∇margin‖과 e^ε배 안에서 맞는가?"
  - **예:** 경사 한 번으로 구한 점수가 이 묶음의 잡음 강건성을 예측한다.
  - **아니오:** 싼 점수가 틀리는 이미지가 있다. 경사 가림(gradient masking)이 만드는 상황이다.
- **대응 관계:**

| 바이올린 | 이 문제 |
|---|---|
| 열 | 이미지 |
| 순위 50개 | 공통 잡음 격자 σ(0.03~3, 로그 간격) |
| 읽기 1회 | 그 σ에서 잡음 64장 추론 |
| log β | −½·log(margin/grad) |
| 규칙 9개 | (실패율 하한 u∈{.1,.3,.5}) × (정답 확률 상한 v∈{.5,.7,.9}) |

  기울기 −2 구간과 인증서는 그대로 쓴다.
- **ε와 분할:** ε는 바이올린과 같이 (0.2, 0.4)이다. 숫자마다 그룹 0~1은 search(40사례, "법칙 성립" 3개), 2~3은 **봉인 holdout**(40사례, 아직 아무 정책도 채점하지 않음)이다.

## 결과 (search 40사례, 낮을수록 좋음, 전부 읽기 = 48,000)

| 정책 (바이올린에서 가져와 그대로 씀) | 읽기 | 전부 읽기 대비 |
|---|---|---|
| seed (한 단계 반사실 예측) | 11,182 | 23.3% |
| 실무식: 이미지마다 파괴점 이분 탐색 (bisect_each) | 9,914 | 20.7% |
| 적응형 탐욕 (SBFE) | 13,458 | 28.0% |
| 증명수 탐색 | 10,533 | 21.9% |
| DRD / EC2 | 28,941 | 60.3% |
| **distilled_a (원리만 남긴 정책)** | **3,560** | **7.4%** |
| p25_t21 (바이올린 최고 기록) | 3,693 | 7.7% |
| p10_t6 | 3,693 | 7.7% |
| p12_t9 | 3,990 | 8.3% |
| (참고) seed 읽기의 사후 가지치기 | 1,842 | 오라클 목표, 실제로 쓸 수 없음 |

- 진화 정책은 바이올린 데이터를 한 번도 벗어나 본 적이 없지만, 처음 보는 AI 감사 문제에서 seed 대비 −67~68%, 실무식 이분 탐색 대비 −63~64% 읽기를 줄였다.
- 바이올린에서도 이분 탐색은 12,556, t21은 3,072다(−76%).
- **원리만 남긴 distilled_a가 바이올린 최고 기록보다 낫다(3,560 < 3,693).** 바이올린에 맞춘 세부 조정(t9 등)은 일부 과적합이고, 이식되는 것은 원리(규칙마다 분리 증인을 약속하고 검증, 뒤집힘 위치는 이분 탐색)다.

## 주의
- 대응 관계는 구성상 같은 꼴이다(어떤 법칙 log t* = s·x + c든 log_beta = −s·x/2로 넣을 수 있다). 주장 범위는 "같은 인증서 구조를 가진 다른 분야 문제로 정책이 옮겨 간다"까지다.
- 모델 1개(MNIST CNN), 가우스 잡음 1종만 썼다. 문헌 기준선은 조정 예산이 같지 않다(DESIGN.md 참고).
- 읽기 1회의 실제 비용은 여기서 싸다(추론 64번). 실제 감사에서는 공격 한 번(PGD·AutoAttack 수백 번 순전파·역전파), 유료 API 호출, 물리 시험이 한 번의 읽기다. 그래서 읽기 수로 보고한다.
