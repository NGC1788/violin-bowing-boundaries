# evolve_v4 — 진화형 연구 루프 설계안 (2026-11-03, Claude)

사용자 요청: 기존 에이전틱 루프를 크게 강화해, 체계적으로 새로운(novel) 방법론과 의미 있는 결과가 나오도록.

**정직한 전제.** 어떤 루프도 "좋은 새 방법이 반드시 나온다"를 보장할 수 없다. 보장하려 들면 점수만 좋은 가짜 결과가 나온다. 이 설계의 목표는 (1) 진짜 개선이 존재할 수 있는 문제에만 자원을 쓰고, (2) 시도 횟수를 수십 배로 늘리고, (3) 나온 결과가 가짜가 아님을 자동으로 걸러내는 것이다.

## 1. 기존 루프가 새 방법을 못 낸 이유 (기록 근거)

| 원인 | 근거 |
|---|---|
| LLM이 실제로 고른 것은 고정 12개 실험의 **실행 순서**뿐 | forecast_v3 agent_rounds 10회, 전부 고정 후보 |
| 가설 하나에 하루치 절차(서면→검토→동결→12개→진단) → 이틀간 가설 약 6개 | 11/2–3 EXECUTION_STATUS |
| 예측 과제의 **개선 여지(천장)를 먼저 재지 않음** (조회 과제만 5.83%를 쟀음) | Markov 0.542를 아무도 의미 있게 못 넘음 |
| 새로움(novelty)을 사후에만 확인 | 각 PRIOR_REVIEW가 결과 뒤 작성 |
| 34명·1,442녹음으로 신경망 학습 → 단순 기준선이 유리 | violin_raw_v1, discovery_v1/v2 |

## 2. 최신 자동 연구 시스템에서 가져올 것

- **AlphaEvolve(DeepMind 2025)·OpenEvolve·ShinkaEvolve·CodeEvolve**: LLM이 실제 코드를 고쳐 변이를 만들고, 자동 평가기가 점수를 매기며, 다양성을 지키는 프로그램 집단(섬·MAP-Elites)으로 진화. 성공 조건은 *값싸고 믿을 수 있는 자동 평가기*.
- **AI Scientist-v2(Sakana)·AIDE·ARTS(2026)**: 실험 트리 탐색 + 정기적으로 트리 전체를 읽고 실패 원인을 진단하는 '과학자' 역할.
- **AIRS-Bench(Meta 2026)**: 아이디어 생성부터 반복 개선까지 평가. 오염되지 않은 평가가 핵심.

## 3. 새 루프 구조 (5층)

**0층 — 문제 선별 관문 (개선 여지 먼저).** 후보 과제마다 기준선 B, 정답을 다 아는 하한(오라클) C, 잡음 바닥을 먼저 계산한다. 여지 1−C/B가 사전 기준(예: 20%) 미만이면 그 과제에 LLM 예산을 쓰지 않는다.
- 후보 A(1순위): **법칙 판정 부분 관측 인증의 조회 수** — 틀린 판정은 정확 검증기가 즉시 탈락시키므로 가짜 개선이 원천 불가. 평가가 초 단위. 현재 최고 910회(고정 9규칙)/1,216회(연속).
- 후보 B: 첼로 미래 예측 벤치마크(78,000행, 9 MB, 저장소에 있음).
- 후보 C: 바이올린 미래 예측 — 천장이 낮을 가능성이 커서 0층에서 먼저 확인.

**1층 — 코드 진화 엔진.** 프로그램 저장소(섬 4개, 행동 특징 격자로 다양성 유지). LLM(Claude CLI 헤드리스, 도구 끔)이 `EVOLVE-BLOCK` 안의 조회 정책·인증 완화·모형 코드를 diff로 수정. 평가는 별도 프로세스·시간제한·네트워크 없음.

**2층 — 다단계 평가.** 작은 부분집합(수 초) → 개발 전체 → 상위 소수만 마지막에 봉인 평가 1회. 개발용은 A/B 측정 계열, 봉인용은 이 과제에 한 번도 쓰지 않은 세션.

**3층 — 과학자·진단 역할.** N세대마다 상위 프로그램·실패 기록을 읽고 실패 원인을 진단하고 새 방향을 주입. 문헌 근거 목록을 갖고 "기존 방법과 무엇이 다른가"를 변이 단계부터 요구.

**4층 — 가짜 결과 차단.** 정확 검증기 일치(불일치=탈락) · 봉인 세트 1회 · 제거 실험(ablation)으로 개선 원인 분해 · 기존 기준선 코드와의 차이 설명 · 모든 시도와 실패를 원장(SQLite)에 기록 · 시드/부분집합 골라내기 금지.

## 4. 산출물

진화된 최고 프로그램 + 개선 원인 분해 + 봉인 평가 1회 결과 + 실패 포함 전체 원장. 개선이 없으면 "여지 X%에서 Y회 시도, 개선 없음"을 그대로 보고.
