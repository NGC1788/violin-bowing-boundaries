# Partial-observation law decision pilot

The fixed endpoint is existence of a common rule from the existing nine-rule bank with a nonempty expanded intercept intersection at slope −2 and tolerance 0.2. Use all 12 speed folders in C1, C_T2, D1 and D2. Keep the original eligible columns and reject a rule if an eligible boundary is missing, left censored, nonpositive or tied. This pilot assumes the original eligibility roster is given at deployment. It is retrospective and does not cover the continuous threshold rectangle.

Compare direct decision certification against reconstructing all nine first boundaries for every eligible column before deciding. Replay the same two query orders for both stops, rank-first across columns and a fixed uniform permutation (seed 20261103, separate stream per sorted group). Each query reveals all nine labels for one waveform. Rank, force and beta are visible. Other labels remain hidden. Check every prefix and verify each decision against the full observed result and the existing full-data solver. Report both classes, all groups, zero-query stops and how many false decisions can also be certified from numerical interval conflict alone. Measure query cost only. No fits or adaptive policy tuning. A useful pilot requires zero disagreement and a strict saving for at least one group under each order. Compare stronger selection policies only as subsequent work.
