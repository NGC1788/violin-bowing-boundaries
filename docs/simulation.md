# 물리 모델 시뮬레이션 (1단계)

2026-09-17. 측정한 Schelleng 격자를 **같은 조건으로 시뮬레이션**하고, **같은 분류기**로 판정해 칸마다 비교한다.

## 모델

`scripts/bowed_string.py`: McIntyre–Schumacher–Woodhouse 계열 디지털 도파관.

| 요소 | 구현 |
|---|---|
| 현 | 활–브리지, 활–너트 왕복 지연선(분수 지연). 반사마다 부호 반전 + 1차 저역통과(직류 이득으로 기본음 Q, 차단주파수로 모서리 둥글기). 필터 지연은 지연선에서 빼서 음높이를 맞춤 |
| 활 | 점 활. 활이 보는 현 임피던스는 구조상 정확히 2Z |
| 마찰 | 쌍곡선 곡선 μ(w) = μd + (μs−μd)·v0/(v0+|w|), 닫힌 식 해. 붙어 있으면 가능한 한 붙어 있고, 미끄러지면 해가 있는 한 미끄러짐(히스테리시스) |
| 구동 | 같은 로봇 시행의 **실측** 활 힘·활 속도 곡선(캐시의 1 kHz 프로파일) |
| 출력 | 브리지 힘 = 2Z × 브리지에 도착하는 속도파. 측정과 같은 분석 창을 50 kHz로 저장 |
| 관측 모델 | 측정의 무접촉 창 표준편차(중앙값)만큼 백색 잡음을 더함 |

모드 합으로 강성 현을 푸는 방식을 먼저 시도했으나 버렸다. 점 활에서는 한 스텝의 활 위치 응답이 시간 간격에 따라 달라져(굽힘 강성) 마찰 해가 수렴하지 않았다.

기본값:
- 음높이는 폴더별 측정 기준 f0, 임피던스 Z는 측정 flyback 법칙의 중앙값이다.
- Q1은 2000, 반사 차단주파수는 6 kHz다.
- 마찰은 Mores(DAGA 2016)의 곡선 맞춤(μs 0.6725, μd 0.346, v0 0.06 m/s)이다.

마찰과 손실 매개변수는 **아직 보정하지 않은 문헌값**이다.

## 로컬 검증

활 위치 β 0.1, 속도 0.1 m/s에서 힘만 올리면 판정 순서가 문헌과 같게 나온다.

| 힘 | 판정 | 비고 |
|---|---|---|
| 0.25 N | 다중 미끄러짐 | |
| 2–3.5 N | 헬름홀츠와 다중 미끄러짐이 번갈아 나옴 | patchy 영역 |
| 4 N | 헬름홀츠 | flyback 1.92, 이론 2Zv/β = 1.89 |
| 10 N | 비주기(raucous) | Schelleng 최대 힘 이론값은 5.8 N |

음높이는 98.03–98.08 Hz다. 속도를 절반으로 줄이면 flyback도 절반이 된다.

## 실행

먼저 폴더마다 10개만 돌려 속도와 동작을 확인한다(지도는 만들지 않고 칸별 판정만 비교).

```bash
bash scripts/run.sh simulate --diagram 2024-03-25_TypeA_sample1 --limit 10
```

전체 6,000개(몇십 분~몇 시간, GPU 사용):

```bash
nohup bash scripts/run.sh simulate --diagram 2024-03-25_TypeA_sample1 > logs/simulate-A1.log 2>&1 < /dev/null &
```

- 결과는 `reports/simulation/<격자>/<실행>/`에 저장된다: `comparison.json`, `regime_map/`의 지도·그림.
- 시뮬레이션 창은 `data/simulation/`에 저장된다(격자 하나에 약 2 GiB).
- `SIMULATION vs MEASUREMENT` 줄에 일치율, 헬름홀츠 영역 IoU, 측정 판정 → 시뮬레이션 판정의 혼동표, 경계 기울기 비교가 나온다.

마찰·손실은 `--mu-s --mu-d --v0 --q1 --corner-hz`로 바꿀 수 있다. **보정은 한 속도(또는 한 현)로만 하고, 다른 속도·현으로 시험한다.**

## 한계

- 점 활, 한 편광, 비틀림 없음, 활털 순응성 없음, 열 마찰 아님.
- 반사 필터는 단순 1차라 모드별 Q를 정밀하게 재현하지 않는다.
- 판정은 측정과 같은 잠정 기준이다.

## 마찰 파라미터 보정 (`run.sh calibrate`)

마찰 곡선과 손실은 측정값이 아니라 문헌값이므로, 측정 지도에 맞춰 찾는다. `scripts/calibrate.py`는 무작위 탐색으로 다섯 값을 바꿔 가며 평가한다: `mu_s`, `mu_d`, `v0`, `q1`, `corner_hz`.

- 평가마다 **파일을 만들지 않는다.** 메모리에서 시뮬레이션하고, 측정과 같은 관측 잡음을 더하고, 같은 분류기로 판정한다.
- 점수는 표본 칸에서의 **헬름홀츠 영역 IoU**이고 라벨 일치율도 함께 기록한다.
- 표본은 β 수준 몇 개를 골라 그 힘 열 전체를 쓴다. 경계가 어디 있는지 보이게 하기 위해서다.
- 모든 평가는 `reports/calibration/<격자>_rate<속도>.jsonl`에 한 줄씩 append된다. 중단해도 같은 명령으로 이어서 하고, 같은 seed면 같은 순서로 탐색한다.
- 첫 평가(index 0)는 항상 문헌값이다. 보정이 문헌값보다 나아졌는지 바로 비교할 수 있다.

```bash
# 한 속도로 보정하고 나머지 속도로 시험
nohup bash scripts/run.sh calibrate --diagram 2024-03-25_TypeA_sample1   --conditions 2024-03-27_r_v2 --hold-out --iterations 400   >> logs/calibrate.log 2>&1 < /dev/null &
tail -f logs/calibrate.log
```

**보정한 속도에서 좋아진 것은 결과가 아니다.** 시험용으로 남겨 둔 속도(`hold-out`)에서의 점수가 물리 모델의 예측력이다.
