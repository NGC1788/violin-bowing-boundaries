# 마지막 바이올린 적용 확인 — 추가 구매 없음

2026-09-13 설계안. 최종 녹음은 아직 수행하지 않았다. 서버에서 핵심 방법과 검증을 완성한 뒤 보유 장비로 단일 세션에서 실행한다. **평가 목적과 규칙은 미리 정하고 실제 실행만 나중에 한다.**

## 정당한 평가 범위

본 연구에 **마이크 파형을 입력받는 음향 분석 모듈이 실제로 포함될 경우**, 동결된 모듈이 실제 바이올린 녹음에서 사전 정의한 주기성·불규칙성 등의 출력을 산출하는지 확인한다. 공개 브리지 힘에서 작동한 분석기가 마이크 신호에서도 검증됐다고 가정하지 않는다.

음향 상태 판별 성능에는 독립 기준이 필요하다. 사전에 작성한 운영적 청취 기준으로 모델 결과를 보지 않고 판정하는 방식 등이 가능하다. 청취 판정도 물리적 Helmholtz 운동의 참값은 아니다. 기준이나 평가 가능한 범주가 부족하면 분류 정확도를 보고하지 않는다.

**최종 모델이 F·v·β만 입력받는 경계 예측기라면**, 힘을 측정하지 않은 녹음은 그 예측 정확도의 검증이 아니다. 부록의 적용 시연으로 명시한다. 녹음을 넣기 위해 필요 없는 음향 모델을 새로 추가하지 않는다. 바이올린 관련 핵심 과학적 내용은 출처가 명확한 바이올린 모델의 계산 사례에서 확보해야 한다.

## 보유 장비로 한 세션

바이올린 한 대, 활, NTG-3, Scarlett 2i2, 녹음 컴퓨터와 기존 연결 구성을 사용한다. 새 거치대·센서·카메라를 구매하지 않는다. 같은 마이크 위치를 유지할 방법은 기존 장비 범위에서 정한다.

- 숙련 연주자 한 명, 바이올린 한 대, 개방 D현부터 시작한다.
- 예시 규모: **운궁 시간 목표 2개 × 접촉 위치 목표 2개 × 반복 3회 × 블록 2개 = 24시행**. 작업량 설계 예시이며 검정력 계산 결과가 아니다.
- 네 조합은 연주 지시 조건이다. 실제 속도·β·힘의 정량 측정값으로 취급하지 않는다.
- 조건 순서는 각 블록 안에서 미리 무작위로 정한다. 한 세션의 두 블록은 서로 다른 날짜의 재현성 시험이 아니다.
- 평가할 음향 변화와 자료 범주의 적합성을 먼저 판단한다. 모든 녹음이 비슷한 안정음이면 상태 판별 성능은 평가 불가능할 수 있다. 결과를 본 뒤 유리한 조건으로 교체하지 않는다.
- 안내 음성·메트로놈 등이 분석 구간을 오염시키지 않게 하고 분석 구간 선택 규칙을 미리 정한다.
- 기존 휴대폰 영상은 선택 사항이다. 영상이나 교정이 없으면 물리 좌표를 임의의 추정값으로 채워 넣지 않는다.

한 번의 세션 안에서 반복 측정한다는 뜻이지, 소리 한 번만 녹음해 결론을 낸다는 뜻은 아니다. 세 악기·두 연주자를 모두 넣는 확장은 필수가 아니다.

## 기록과 보고

48 kHz·24-bit PCM을 녹음 설정 후보로 두고 실제 설정을 기록한다. 입력 게인·마이크 위치와 방향을 고정하고 자동 게인·정규화·노이즈 제거 적용 여부를 기록한다. 원본은 보존하고 후처리는 별도 사본에 수행한다. 음압 교정이 없으면 진폭을 절대 음압으로 해석하지 않는다.

최종 세션 전에 코드·모델, 전처리, 주 평가 출력, 독립 판정 절차, 연주 지시·순서·반복 수, 클리핑·녹음 중단 등 기술적 실패의 처리 규칙을 고정한다.

계획된 모든 시행, 기술적 재녹음의 이유, 모델 실패·판정 보류를 기록한다. 잘 나온 예시만 남기지 않는다. 한 연주자·한 악기·한 세션의 결과를 전체 바이올린이나 연주자 집단으로 일반화하지 않는다.

마지막 세션은 센서 없이 실제 바이올린 힘 경계를 검증하는 절차가 아니다. 이 범위를 받아들이는 것이 추가 구매 없이 실행하는 현재 설계의 전제다.
