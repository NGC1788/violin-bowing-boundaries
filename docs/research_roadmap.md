# 연구 단계와 검증 기준

2026-09-13 수정. **서버에서 방법 개발과 본 검증을 수행하고, 마지막에 보유 바이올린으로 제한적인 적용 확인을 한다. 추가 구매는 하지 않는다.** 이전의 센서 제작·대규모 자체 수집 중심 실행안을 대체한다. 제출한 원본 계획서를 수정하거나 학교의 변경 승인을 받은 것으로 간주하지 않는다.

## 확정한 운영 범위

- 새 센서, 촬영 장비, 저장장치, 유료 모델/API를 구매하지 않는다.
- 힘 센서 제작·교정과 자체 학습 데이터 대량 수집을 필수 작업에서 제외한다.
- 공개 실측 자료 분석, 물리 모델 재현, 수치 검증, 기준 방법·제안 방법 비교를 서버에서 수행한다.
- 바이올린은 마지막의 단일 녹음 세션에 사용한다. 한 세션 안에서 사전 계획한 여러 시행을 반복한다. 세 악기를 모두 사용할 필요는 없다.
- 마지막 녹음이 없어도 핵심 방법론의 주장이 공개 자료와 계산 검증으로 뒷받침되어야 한다.

## 유지할 연구 질문과 방법 후보

활–현 연주 가능 영역을 물리 모델과 데이터 기반 모델이 얼마나 정확하게 예측하는지, 수치 근사·물리 모델의 불일치·관측 불확실성을 고려하면 어떤 개선이 가능한지를 연구한다.

먼저 검토할 후보는 **수치해석 해상도에 따른 차이와 공개 실측에 대한 모델의 불일치를 구분하며 경계와 불확실성을 추정하는 방법**이다. 이 구분이 자료로 식별 가능한지부터 확인한다. 분리할 수 없는 항은 통합 불확실성이나 민감도 범위로 남긴다.

다중 충실도 Gaussian process, 능동 샘플링, 물리 사전정보 자체는 기존 기술이다. 조합만으로 신규성을 주장하지 않는다. 가장 가까운 기존 방법을 재현하고 어떤 반복 가능한 실패를 새 방법이 해결하는지 정한다. 성능 개선과 게재 가능성은 아직 검증되지 않았다.

## 증거의 역할과 한계

| 자료·계산 | 역할 | 주장 한계 |
|---|---|---|
| 공개 로봇 운궁·첼로 강체 현 실측 | 상태 분석, 모델과 측정의 비교, 제외한 현·속도·장력·설치 조건의 시험 | 실제 바이올린 몸통이 포함된 실험이 아니다 |
| 출처가 있는 바이올린 현·몸통 모델 | 바이올린에 대한 계산적 적용과 민감도 분석 | 보유한 세 바이올린의 디지털 트윈이나 실제 힘 경계가 아니다 |
| 마지막 자체 마이크 녹음 | 본 연구에 실제로 포함된 음향 모듈의 제한적 적용 확인 또는 부록 시연 | 활 힘을 측정하지 않으므로 F-v-β 경계 정확도 검증이 아니다 |

공개 자료의 네 채널은 활 힘·활 속도·브리지 힘·너트 힘이며 마이크 음압이 아니다. [공식 자료 설명](https://zenodo.org/records/17749111). 기존 실험 자료와 새로운 마찰 모델을 비교한 연구는 계산 중심 접근의 선행 사례지만, 그 논문의 자료·코드를 즉시 사용할 수 있다는 뜻은 아니다. [Woodhouse와 Galluzzo, 2025](https://link.springer.com/article/10.1007/s11249-025-02062-4).

## 서버에서 수행할 순서

1. **자료 감사:** 첫 아카이브의 체크섬, 비압축 용량, 파일 구조, 단위·시간축, 라벨 유무와 생성 절차를 확인한다. 현재 원시자료 다운로드 완료·압축 내부 검증은 확인되지 않았다.
2. **계산 모델 확보:** 구현과 매개변수 출처를 확인하고 바이올린 계산 사례의 재현 가능성을 먼저 판단한다. 전체 3D 유한요소 악기를 새로 만드는 일은 기본 범위가 아니다.
3. **수치 검증:** 해상도·시간 간격에 따른 상태 영역의 변화를 확인한다. 정밀 계산 한 번의 출력을 검증 없이 참값으로 선언하지 않는다.
4. **공정한 기준 비교:** 고전 물리 경계, 재현 가능한 현대 물리 모델, 통계적 경계 모델, 제안법에 가까운 기존 방법을 비교한다. 보정 정보와 계산 예산을 기록하고 맞춘다.
5. **방법 개발과 독립 시험:** 반복 가능한 실패를 근거로 제안법을 구체화한다. 시행·현 샘플·세션 등의 단위로 시험 자료를 분리한다. 첼로 실측과 바이올린 계산의 결과는 구분한다.
6. **최종 규칙 고정:** 바이올린 녹음 전에 코드 commit, 모델, 전처리, 평가 기준, 제외·실패 처리 규칙을 고정한다.
7. **마지막 적용 확인:** [최종 바이올린 확인 계획](final_violin_check.md)에 따라 보유 장비로 한 세션을 실행한다. 실패와 평가 불가능한 항목도 남긴다.

## 엄격한 평가

- 같은 시뮬레이터의 합성 자료에서만 높은 성능을 보이면 그 시뮬레이터를 근사한 성능이다. 실제 예측 개선은 제외한 실측 자료에서 별도로 입증한다.
- 모든 창·증강본·동기화 채널은 원래 시행과 같은 split에 둔다. 전처리·보정·선택 과정은 시험 자료를 보지 않는다.
- 경계가 불연속이거나 안정 영역에 구멍이 있으면 보존한다. 측정 범위 밖의 경계를 마지막 측정점으로 대체하지 않는다.
- 전체 상태 영역·경계 오차·불확실성 보정·계산 비용을 함께 평가한다. 유리한 조건만 골라 개선을 주장하지 않는다.
- 마지막 녹음을 보고 모델을 수정하면 그 자료는 개발 자료다. 동일 자료로 독립 시험 성능을 다시 주장하지 않는다.
- 좋은 녹음 장비는 파형 기록을 돕지만 활의 정상력이나 접촉 상태를 직접 측정하지 않는다.

## 남은 기간

9월에는 자료·모델 재현 가능성을 확인하고 실제 실패 사례를 근거로 방법을 정한다. 10월에는 구현과 본 비교를 수행하고 평가 규칙을 고정한다. 11월 초에 마지막 바이올린 세션을 두어 분석·작성 시간을 남긴다. 11월 중순에는 결과와 재현 기록을 정리하고 말 제출을 준비한다.

서버 GPU 실행은 제공된 로그에서 확인했지만, 데이터 파서·시뮬레이터·제안 모델·연구 성능은 아직 완료되지 않았다. 자료 규모에 따라 선택 다운로드·부분 변환을 사용하며 추가 저장장치 구입을 전제로 하지 않는다.
