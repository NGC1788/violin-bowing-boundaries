# 잠정 상태 판정과 연주 가능 영역 지도

2026-09-17. [격자 복원](trial_audit.md#다음--격자-복원)까지 끝난 서버에서 RustDesk로 연 Ubuntu 터미널에서 실행한다.

공개 자료에는 **상태 라벨이 없다.** 이 도구는 시행마다 분석 창 안의 3열(공개 설명: 브리지 힘)만 보고 상태를 **규칙으로 잠정 판정**하고, 속도별로 (β, 힘) 평면에 연주 가능 영역 지도를 그린다. 판정 기준은 잠정치이고, 공개된 기준 라벨이 아니다. **판정이 맞는지 `examples.png`의 실제 파형으로 먼저 확인한 뒤에만 지도를 해석한다.**

## 판정 방법

헬름홀츠 운동이면 브리지 힘이 톱니파가 되고, **한 주기에 급격한 되돌아옴(flyback)이 한 번** 있다. 이중·다중 미끄러짐이면 비슷한 크기의 되돌아옴이 한 주기에 여러 번 생긴다. 자료를 만든 연구진도 같은 원리를 쓴다. 이들은 Woodhouse·Galluzzo 알고리즘으로 브리지 힘을 계단 모양으로 detrend하고, 계단 한 칸의 높이를 이론적 헬름홀츠 flyback 크기와 비교한다(van Walstijn 외, Acta Acustica 2026, 3.2.2절). 시행별 라벨은 공개되지 않았다.

이 도구는 창 안의 3열에서 다음을 잰다.

| 값 | 계산 |
|---|---|
| 주기성 | 자기상관이 40–160 Hz 범위에서 가장 큰 지연의 값 |
| 평균 한 주기 | 창을 그 주기(소수점 포함)로 잘라 모든 주기를 평균한 파형. 표본 잡음이 주기 수의 제곱근만큼 줄어든다 |
| flyback 수 | 평균 한 주기를 꺾이는 점 사이의 구간으로 나눈다. 평균 파형 표준오차의 3배보다 작은 되꺾임은 잡음으로 보고 무시한다. 가장 크고 빠른 구간의 방향을 되돌아옴 방향으로 잡고, 그 방향 구간 중 **가장 큰 것의 절반 이상**만 센다 |
| 둘째/최대 비 | 그 방향에서 두 번째로 큰 구간 ÷ 가장 큰 구간. 0.5 미만이면 flyback이 1개다 |
| 잡음 바닥 | 1열 창 평균이 0 이하인 시행(활 접촉 없음)의 창 표준편차 중앙값 × 3. 그런 시행이 10개 미만이면 0.02를 쓴다 |

| 판정 | 조건(잠정) |
|---|---|
| `no_oscillation` | 창 표준편차 < 잡음 바닥 |
| `aperiodic` | 주기성 < 0.5 |
| `ambiguous` | 주기성 0.5–0.8, 또는 아래 어느 것에도 해당하지 않음 |
| `subharmonic` | 주기성 ≥ 0.8이고 기본주파수 < 폴더 기준 기본주파수 × 0.75 |
| `helmholtz` | 주기성 ≥ 0.8, flyback 1개 |
| `multiple_slip` | 주기성 ≥ 0.8, flyback 2개 이상 |

판정에는 3열의 **모양**만 쓴다. 그 시행 자신의 활 힘·활 속도·β는 쓰지 않는다. 1열은 잡음 바닥이라는 전역 상수 하나를 정할 때만 쓴다.

### 왜 바꿨나

첫 전체 실행(`20260917T104233Z_0e8ffc33`)은 표본 간 차이 `|diff|`로 급변 구간을 세고, 가까운 구간을 이어 붙였다. 실제 파형(`examples.png`)에서 **깨끗한 톱니파가 0.03–2.83 slips/주기**로 나왔다. 되돌아옴이 여러 표본에 퍼져 있으면 경사 구간의 표본 잡음이 기준을 넘고, 이어 붙이기가 창 전체를 사건 하나로 만든다. 같은 조건의 합성 신호에서도 옛 방식은 0.03이 나온다. 활 접촉이 없는 ±0.1 수준의 잡음 창은 0.02 기준 아래라서 `aperiodic`/`ambiguous`로 잘못 분류되었다.

### 독립 확인: flyback 법칙

이상적인 헬름홀츠 운동에서 flyback 크기는 **ΔF = 2 Z v_b / β**이다(Z: 현의 특성 임피던스). 판정에는 크기를 쓰지 않는다. 대신 헬름홀츠로 판정된 시행에서 log ΔF를 log v_b(2열 창 평균)와 log β에 맞춰 지수를 구한다. 이론값은 +1과 −1이다. 판정과 독립인 물리 법칙이 성립하는지로 라벨을 확인하는 것이다. Z는 같은 모노코드를 쓴 van Walstijn 외(2026) 표 1에서 계산한 1.175 kg/s와 비교만 한다. 현 종류가 다를 수 있다.

## 경계와 기울기

β 수준마다 헬름홀츠로 판정된 힘 순위를 모은다. **2칸 이하의 비헬름홀츠 칸은 영역 안의 오판으로 보고 이어 붙인다.** 가장 넓은 구간의 아래·위 끝 바깥 힘과의 기하평균을 경계로 둔다. 구간 끝이 격자 가장자리에서 2칸 이내이면 가장자리의 오판과 진짜 경계를 구분할 수 없으므로 **중도절단**으로 처리하고 맞춤에서 뺀다. 남은 경계로 log 힘–log β 직선을 맞춰 기울기와 표준오차를 낸다. Schelleng 이론은 아래 경계 기울기 −2, 위 경계 −1을 예측한다.

힘 좌표는 각 힘 순위에서 β 수준들에 걸친 1열 창 평균의 중앙값이다. 약한 힘 쪽에서는 시행별 1열 값이 0 이하로 떨어지기도 하므로 시행별 값보다 이 중앙값을 쓴다.

## 실행

먼저 폴더마다 3개로 동작만 확인한다(몇 초).

```bash
cd "$HOME/research/violin-bowing-boundaries"
git pull --ff-only
git log -1 --oneline
bash scripts/run.sh regime-map --limit 3 --no-plot
```

`classes:` 줄이 나오면 전체를 실행한다. 6,000개 신호를 다시 읽으므로 **몇 분** 걸린다.

```bash
mkdir -p logs
TASK_LOG="$(mktemp "$PWD/logs/regime-map-XXXXXXXX.log")"
nohup bash scripts/run.sh regime-map > "$TASK_LOG" 2>&1 < /dev/null &
printf 'PID: %s\nLog: %s\n' "$!" "$TASK_LOG"
tail -f "$TASK_LOG"
```

끝나면 `REGIME MAP` 아래에 잡음 바닥 줄, 폴더당 6줄, `FLYBACK LAW` 줄, `Plot:` 네 줄이 나온다. **출력 전체**를 공유하고, 그림 네 개(`regime_map.png`, `examples.png`, `features.png`, `flyback_law.png`)를 화면에 띄워 캡처한 뒤 **이미지 자체**를 채팅에 끌어다 놓는다.

## 결과 읽기

| 줄 | 의미 |
|---|---|
| `reference f0` | 폴더 기준 기본주파수와 분포. 명목 98 Hz 근처여야 한다 |
| `classes` | 판정별 시행 수 |
| `lower/upper boundary slope ±` | 기울기와 표준오차. `n`은 맞춤에 쓴 β 수준 수, `beta span`은 그 β 범위의 배율, `censored`는 격자 밖으로 판정된 수준 수 |
| `interior cells bridged` | 영역 안에서 이어 붙인 오판 칸 수. 크면 판정이 불안정하다는 뜻이다 |
| `labels of off-plateau windows` | 창이 일정 속도를 벗어난 시행의 판정 분포 |
| `labels of column-1<=0 windows` | 1열 평균이 0 이하인 시행의 판정 분포. 대부분 `no_oscillation`이어야 한다 |
| `noise floor` | 적용된 잡음 바닥과 그 근거(활 접촉 없는 시행 수, 중앙값, 95백분위) |
| `flyback-frac sensitivity` | flyback 기준을 0.3–0.7로 바꿨을 때의 헬름홀츠 수와 경계 기울기. **기준에 따라 기울기가 크게 흔들리면 결론을 내릴 수 없다** |
| `Helmholtz H*beta/(2 v_b)` | 폴더별 헬름홀츠 시행의 Z 추정 분포. 세 폴더가 비슷해야 한다 |
| `FLYBACK LAW` | 세 폴더를 합친 지수 맞춤. 속도 +1, β −1에 가까우면 헬름홀츠 라벨이 물리적으로 맞다는 독립 근거다 |

그림 네 개의 용도는 다음과 같다.

| 그림 | 볼 것 |
|---|---|
| `examples.png` | 판정별 실제 파형. 검은 선은 평균 한 주기, 빨간 삼각형은 센 flyback이다. **삼각형이 되돌아옴마다 하나씩 찍혔는지** 본다 |
| `features.png` | 진폭(로그), 주기성, 둘째/최대 비의 분포와 기준선. 기준선이 분포의 골짜기에 놓이는지 본다 |
| `flyback_law.png` | 헬름홀츠 시행의 flyback 크기 대 2 v_b/β. 한 직선에 모이면 법칙이 성립한다 |
| `regime_map.png` | 속도별 (β, 힘) 판정 지도와 경계 직선 |

`n`이 작거나 `beta span`이 좁으면 표준오차가 커진다. 그 기울기는 이론과의 일치·불일치를 말할 근거가 약하다.

## 기준 바꾸기

판정 기준은 옵션으로 바꿀 수 있다. 바꾼 값은 보고서에 그대로 기록된다. **결과를 보고 원하는 기울기가 나오도록 기준을 고르면 안 된다.** 기준 변경은 `examples.png`에서 확인한 오판을 근거로만 하고, 바꾼 이유를 남긴다. flyback 기준의 영향은 매 실행의 민감도 줄에 이미 기록된다.

```bash
bash scripts/run.sh regime-map --flyback-frac 0.5 --hysteresis-sigma 3 --noise-floor-factor 3 --min-amplitude 0.02 --min-periodicity 0.8 --max-aperiodic 0.5 --subharmonic-ratio 0.75 --max-hole 2
```

## 이 결과로 말할 수 없는 것

- 공개된 기준 라벨과 비교해 검증된 판정이 아니다. 연구진의 알고리즘은 원리만 공개되어 있고 세부 허용오차와 시행별 라벨은 없다. 연구진은 이중 미끄러짐, S-motion, 다중 flyback도 따로 구분하지만, 이 도구는 이들을 `multiple_slip` 하나로 묶는다.
- 공개 자료는 첼로 G현을 강체 모노코드에 건 로봇 운궁이다. 실제 바이올린의 연주 가능 영역이 아니다.
- 창이 일정 속도를 벗어난 시행은 설정 속도가 아닌 조건에서 판정되었다.
